# 工单 26 — Skill 资产表结构与模型基座 · 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 skill 资产演进到新存储形态——资源拆独立表（挂版本级）、加上架位与 Git 来源标记、name 放宽、PLATFORM 移除——并保持既有功能全回归。

**Architecture:** 方案 A「领域模型零重构，只动持久化」：`SkillContent` 值对象与消费方（物化网关/挂载解析）不动，变更收敛在 DDL 三份脚本 + DO/Mapper/Converter/RepositoryImpl + 领域根两个新属性 + publish/unpublish 接口。

**Tech Stack:** Java 25 / Spring Boot 4.1 / MyBatis Plus / MapStruct / PostgreSQL（主库 + pg-test）/ H2（unit-test）/ Vue3 + Element Plus（前端）。

**Spec:** `docs/design/2026-08-25-工单26-skill资产表结构与模型基座-设计.md`（本计划从该设计出发，执行者需同时读两者）

## Global Constraints

- `published` 列类型 **int4（0=下架，1=上架）**；领域模型 boolean；DTO Integer（用户定案，禁改 boolean 列）。
- `ai_skill.name` 放宽 **varchar(255)**（领域校验 `NAME_MAX_LENGTH` 同步 255）。
- `SkillOwnerLevel` 值域 **TENANT/USER**（删除 PLATFORM）。
- 资源行**只插不改**；`(version_id, resource_path)` 唯一索引 `WHERE deleted = 0`；无数据库级 FK。
- `git_source_id` 为裸列软关联（`ai_skill_git_source` 表归工单 29，本票不建）。
- `listVersions` 语义保持「含内容含资源」——唯一消费方 `AgentRuntimeAssembler`（session 模块）因此零改动。
- **三份建表脚本必须同步**：`sql/postgresql/ruoyi-vue-pro.sql`（AI 段 6216-6298）、`nexai-module-ai/src/test/resources/sql/create_tables.sql`（H2）、`nexai-module-ai/src/test/resources/sql/pg/create_tables.sql`；两份 clean 脚本同步加资源表清理。
- 注释一律中文；DDD domain 层零框架依赖；转换用 MapStruct（禁 BeanUtils）。
- commit 风格对齐仓库惯例：`feat(skill): …` 中文描述。

```java
/** 版本资源 Map → 资源行（versionId 为版本落库后的 DB 主键） */
default List<SkillResourceDO> contentToResourceDOs(Long versionId, SkillContent content) {
    if (content == null || content.getResources().isEmpty()) {
        return List.of();
    }
    return content.getResources().entrySet().stream()
            .map(entry -> {
                SkillResourceDO row = new SkillResourceDO();
                row.setVersionId(versionId);
                row.setResourcePath(entry.getKey());
                row.setResourceContent(entry.getValue());
                return row;
            })
            .toList();
}

/** 资源行 + markdown → 领域值对象（reconstitute 用） */
default SkillContent toContent(String markdown, List<SkillResourceDO> rows) {
    if (rows == null || rows.isEmpty()) {
        return SkillContent.of(markdown, null);
    }
    Map<String, String> resources = new LinkedHashMap<>(rows.size());
    rows.forEach(row -> resources.put(row.getResourcePath(), row.getResourceContent()));
    return SkillContent.of(markdown, resources);
}
```

```java
@Override
public Long saveVersion(SkillVersion version) {
    SkillVersionDO dataObject = skillConverter.toVersionDataObject(version);
    skillVersionMapper.insert(dataObject);
    // 版本行落库拿到主键后展开资源行（只插不改：版本不可变的物理体现）
    skillResourceMapper.insertBatch(
            skillConverter.contentToResourceDOs(dataObject.getId(), version.getContent()));
    return dataObject.getId();
}

@Override
public SkillVersion findVersion(Long skillId, Integer versionNo) {
    SkillVersionDO dataObject = skillVersionMapper.selectOne(
            new LambdaQueryWrapperX<SkillVersionDO>()
                    .eq(SkillVersionDO::getSkillId, skillId)
                    .eq(SkillVersionDO::getVersionNo, versionNo));
    return dataObject == null ? null : reconstituteVersion(dataObject);
}

@Override
public void deleteByIdCascade(Long id) {
    // 资源行先于版本行清理（软删语义下，selectList 自动滤已删行）
    skillVersionMapper.selectListBySkillId(id).forEach(versionDO ->
            skillResourceMapper.delete(new LambdaQueryWrapperX<SkillResourceDO>()
                    .eq(SkillResourceDO::getVersionId, versionDO.getId())));
    skillVersionMapper.delete(new LambdaQueryWrapperX<SkillVersionDO>()
            .eq(SkillVersionDO::getSkillId, id));
    skillMapper.deleteById(id);
}

private SkillVersion reconstituteVersion(SkillVersionDO dataObject) {
    return SkillVersion.reconstitute(dataObject.getId(), dataObject.getSkillId(),
            dataObject.getVersionNo(),
            skillConverter.toContent(dataObject.getSkillMarkdown(),
                    skillResourceMapper.selectListByVersionId(dataObject.getId())),
            dataObject.getNote(), dataObject.getCreateTime());
}
```

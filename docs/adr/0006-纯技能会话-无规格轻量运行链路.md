# 纯技能会话：无规格的轻量运行链路

终端用户场景「只选技能直接聊天」不经过智能体规格体系：直接以 ReActAgent 挂载单个技能开聊。拒绝为该场景合成隐式规格（AgentSpec 模板）——规格承载的模型选择、挂载固化、发布门禁对此场景全是冗余；也拒绝为每个技能生成专属规格（资产爆炸、混淆 Skill 与 AgentSpec 概念）。

决策：

1. **无规格直连**：ReActAgent + 单技能挂载，不设系统提示（SKILL.md 与 agentscope 默认即全部上下文）。
2. **两步轻配置**：用户选技能 + 自选模型（模型列表 = 租户内全部可用渠道模型，无额外白名单）；用户偏好记忆（下次自动选中上次模型，可改）。
3. **上架门槛**：技能增加上架状态位；终端目录仅上架技能可见，管理端调试台可选全部（调试语义包含半成品）。
4. **活引用与实例复用**：无发布动作故无固化副本，会话活引用技能当前生效版本；实例按「技能 + 当前版本号 + 模型」常驻复用，技能版本推进即失效重建——进行中会话沿用旧实例至结束，新会话用新版。
5. **会话与治理不脱锚**：Session 照建照续（specId 放开可空，新增技能与模型引用），用量/审计沿用既有会话链路，聚合维度补技能侧统计。

## Considered Options

- 隐式规格（选技能时按模板合成 AgentSpec，走既有发布/快照/实例链路）——**拒绝**：规格体系的三样机制（模型预配、挂载固化、发布门禁）对该场景全是空转；用户明确「不需要 agentspec」。
- 独立轻量链路且不建会话——**拒绝**：会话持久化/可续聊与用量审计是终端页面的既有依赖，脱锚即两套治理。

关联：ADR-0005（技能资产统一管理——本 ADR 的活引用读取其版本链）。

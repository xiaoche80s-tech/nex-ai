# 多智能体协作经子智能体编排实现，不自建 DAG 工作流引擎

产品能力清单中含"工作流编排"，但 agentscope-java 无 DAG/Pipeline 引擎（仅有子智能体编排 SubAgentTool 与控制面任务板），而自建 DAG 引擎（含可视化编辑器，旧版 ADR-0002 方案已随白纸重来废弃）是季度级投入。决定：**多智能体协作现阶段一律经子智能体编排实现**（主 agent 的 systemPrompt 定义分工 + SubAgentTool 路由派发）；显式 DAG 引擎仅在出现"必须确定性流转"的真实客户需求后立项，需求未至不预建。

## Consequences

- 在 DAG 立项前：无确定性流转保障、无人工审批节点流、无可视化编排——产品话术中不承诺"工作流编排"能力。
- 确定性场景的临时出路：技能/系统提示约束 + 权限引擎白名单收紧行为，而非编排引擎。

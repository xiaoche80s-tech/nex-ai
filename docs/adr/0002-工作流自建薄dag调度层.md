# 工作流自建薄 DAG 调度层，执行映射到 agentscope 委派原语

调研证实 agentscope v2 不存在任何 DAG/StateGraph 工作流引擎（其编排哲学是 ReAct 循环 + 工具化委派）。平台的工作流功能（M3 落地）自建薄调度层：编排图（节点/边/条件分支/人工审批节点）存 PostgreSQL，节点执行映射到 agentscope 现成委派原语（agent_spawn 同步屏障、后台任务、interrupt/HITL），不引入第三方工作流引擎。调度层只负责图遍历与节点编排，不重新实现智能体执行。

确定性 DAG 是工作流功能的唯一形态；"LLM 自主编排"场景不进工作流引擎，由 AgentSpec 定义子智能体 + Teams 协作覆盖。

## Considered Options

- 自建薄调度层映射 agentscope 原语（选定）
- 引入第三方工作流引擎（LangGraph4j、Flowable 等——与 agent 运行时割裂，放弃）
- 纯 agentscope 自主委派（无可视化画布，不满足企业级平台预期，放弃）

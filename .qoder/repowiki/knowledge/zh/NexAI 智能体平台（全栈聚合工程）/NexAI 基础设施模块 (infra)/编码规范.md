- 每个功能子域遵循 controller/service/dal/enums/convert 的分层结构，DO 与 VO 之间通过 MapStruct Convert 类进行转换。
- 跨模块能力以 api 包中的接口形式暴露（如 ConfigApi、FileApi、WebSocketSenderApi），实现类放在 impl 子包中。
- 错误码与字典常量集中定义在 enums 包的 ErrorCodeConstants、DictTypeConstants 等文件中，供各子域复用。
- 管理后台控制器统一放在 controller/admin 下并按功能子域再分子目录，VO 随控制器放置于同名 vo 子包。
- 可插拔能力通过 Spring Boot AutoConfiguration 装配（如 file/core/config/NexaiFileAutoConfiguration），由 @EnableConfigurationProperties 注入配置。

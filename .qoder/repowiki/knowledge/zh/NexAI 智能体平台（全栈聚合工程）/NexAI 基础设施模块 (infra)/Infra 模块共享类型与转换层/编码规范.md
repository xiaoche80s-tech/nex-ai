- 错误码统一在 `ErrorCodeConstants` 接口中以 `new ErrorCode(编号, 描述)` 形式按功能域分组声明，编号遵循 1-001-xxx-xxx 分段规则。
- 字典类型常量集中在 `DictTypeConstants` 接口中，以 `String` 常量形式维护字典 key 与中文说明。
- 业务枚举采用 Lombok `@AllArgsConstructor + @Getter` 组合，并通过静态 `valueOf(Integer)` 配合 Hutool `ArrayUtil.firstMatch` 实现按整型值反查。
- MapStruct 转换器以 `interface` + `@Mapper` 形式定义，并通过 `static INSTANCE = Mappers.getMapper(...)` 暴露单例供调用方直接使用。
- DO 与 VO 之间的字段名差异通过 MapStruct `@Mapping(source=..., target=...)` 显式声明，复杂类型转换使用 `@Named` 标注的 default 方法。
- MQ 相关代码按 consumer/producer/message 三目录物理隔离，并以 `package-info.java` 注释说明职责，便于后续逐步填充实现。

模块按职责划分为 framework（内部实现）、api（对外暴露的接口）和 websocket（示例消息处理）三个子目录：
- framework/file/core/client 采用策略+工厂模式：定义 FileClient 接口与 AbstractFileClient 模板基类，通过 FileStorageEnum 枚举集中声明 DB/LOCAL/FTP/SFTP/S3 五种存储类型及其对应 Client/Config 类；FileClientFactoryImpl 使用反射根据 storage 编号动态创建并缓存客户端实例，支持运行时 createOrUpdateFileClient 刷新配置。
- framework/codegen/config、security/config、web/config、file/config 以 Spring @Configuration + EnableConfigurationProperties 形式注册各子能力的自动装配入口。
- api 包仅包含纯接口及薄实现（如 ConfigApiImpl、FileApiImpl、WebSocketSenderApiImpl、日志 Api 实现），作为 infra 模块向其他业务模块暴露的稳定契约，实现与具体存储、WebSocket 框架的解耦。
- websocket 包提供 DemoReceiveMessage/DemoSendMessage 消息体以及 DemoWebSocketMessageListener，基于上层 framework.websocket.core 的 WebSocketMessageListener/WebSocketMessageSender 完成单发与群发示例。
依赖方向：api → framework（实现），websocket → 上层 websocket 框架；infra 不反向依赖业务模块。

- 新增文件存储后端时，在 FileStorageEnum 中登记 storage 编号、对应的 FileClientConfig 与 FileClient 实现类，由工厂通过反射统一创建。
- 对外能力以 api 包中的接口定义契约，具体实现放在 framework 或同包 Impl 后缀类中，便于其他模块通过接口消费。
- 可插拔组件通过独立的 @Configuration 类配合 @EnableConfigurationProperties 暴露配置项，保持各子功能装配边界清晰。
- 抽象基类采用模板方法模式（如 AbstractFileClient 的 init/doInit/refresh），将通用生命周期逻辑下沉，子类只关注差异化初始化。
- WebSocket 消息处理通过实现 WebSocketMessageListener<T> 并以 getType() 返回消息类型路由，消息体拆分为 Send/Receive 两类 POJO。

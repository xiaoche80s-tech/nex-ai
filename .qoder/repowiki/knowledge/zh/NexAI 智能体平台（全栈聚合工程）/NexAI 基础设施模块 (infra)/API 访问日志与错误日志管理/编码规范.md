- 每个日志类型均遵循 Controller-Service-API 三层结构，Controller 仅做参数校验、权限注解与 VO/DO 转换，业务逻辑下沉至 Service。
- 对外暴露的管理接口统一返回 `CommonResult<T>`，分页接口返回 `PageResult<T>`，并使用 `@Validated` + JSR-303 注解对入参进行校验。
- 所有管理后台接口通过 `@PreAuthorize("@ss.hasPermission('infra:xxx:action')")` 声明细粒度权限，导出接口额外标注 `@ApiAccessLog(operateType = EXPORT)`。
- VO 与 DO 之间的转换统一通过 `BeanUtils.toBean` 完成，避免手写映射。
- 跨模块日志写入通过实现框架 `*CommonApi` 接口并以 `@Service` 注册，内部再委托给对应 Service，保持 API 层薄转发。
- 日志数据写入前对超长字段（requestParams、resultMsg）使用 `StrUtils.maxLength` 截断，并借助 `TenantUtils.executeIgnore` 兜底租户上下文缺失时的插入。

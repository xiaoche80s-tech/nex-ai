模块按 controller/service/api 三层划分：
- controller/admin/logger：`ApiAccessLogController` 与 `ApiErrorLogController` 暴露管理后台 REST 接口（/infra/api-access-log、/infra/api-error-log），提供 get、page、export-excel 以及错误日志的 update-status 操作，使用 `@PreAuthorize` 进行权限控制，并通过 `ExcelUtils` 导出 Excel。
- service/logger：`ApiAccessLogService` / `ApiErrorLogService` 及其 Impl 实现业务逻辑，依赖 MyBatis Mapper（如 `ApiAccessLogMapper`）完成 CRUD；`cleanAccessLog` 通过循环调用 `deleteByCreateTimeLt` 分批清理过期日志，并在写入时借助 `TenantUtils.executeIgnore` 处理租户上下文缺失场景。
- api/logger：`ApiAccessLogApiImpl`、`ApiErrorLogApiImpl` 实现框架提供的 `ApiAccessLogCommonApi` / `ApiErrorLogCommonApi` 接口，作为跨模块 RPC/内部调用入口，仅转发到对应 Service。
- vo/apiaccesslog、vo/apierrorlog：存放请求/响应 VO，由 Controller 通过 `BeanUtils.toBean` 在 DO 与 VO 之间转换。
依赖方向为 controller → service → mapper/dal，api 层独立于 controller 面向其他模块暴露写入能力。

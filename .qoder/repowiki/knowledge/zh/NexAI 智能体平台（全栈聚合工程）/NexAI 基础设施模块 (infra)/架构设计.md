模块按横切关注点划分为多个子域（codegen/config_and_db/file_storage/job_scheduling/api_logging/framework_core/shared_types/tests），通过分层目录组织：controller/admin 暴露管理后台 HTTP 接口，service 实现业务逻辑，dal/DO+Mapper 完成持久化，enums 与 convert 提供共享类型与 MapStruct 转换。跨模块协作由 api 包中的接口（ConfigApi、FileApi、WebSocketSenderApi、日志写入 Api）统一对外发布，业务模块仅依赖这些接口而非 infra 内部实现；framework_core 下的 Spring Boot AutoConfiguration（如 NexaiFileAutoConfiguration、SecurityConfiguration、InfraWebConfiguration、AdminServerConfiguration）在启动时装配各子域能力。job 包内的清理 Job（JobLogCleanJob、AccessLogCleanJob、ErrorLogCleanJob）作为 Quartz 任务定期维护日志数据，tests 使用 H2 内存库对各 service 进行独立断言。

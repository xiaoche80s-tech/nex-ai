模块以两个并列子包组织：`excel.core` 封装 Excel 能力，`dict` 封装数据字典能力，二者通过 `DictFrameworkUtils` 共享字典解析逻辑。
- 自动装配：通过 `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 注册 `NexaiDictAutoConfiguration`，在启动时注入 `DictDataCommonApi` 并初始化静态工具类。
- Excel 层（`excel/core`）：`ExcelUtils` 作为统一入口，封装 FastExcel 的写（`write` 到 HttpServletResponse）与读（从 MultipartFile），默认注册 `ColumnWidthMatchStyleStrategy` 自适应列宽、`SelectSheetWriteHandler` 实现固定 Sheet 下拉框、`LongStringConverter` 避免精度丢失；自定义 Converter（`DictConvert`、`MultiDictConvert`、`MoneyConvert`、`JsonConvert`、`AreaConvert`）配合 `@DictFormat`、`@ExcelColumnSelect` 等注解完成字段级转换；`function.ExcelColumnSelectFunction` 提供下拉函数式接口。
- 字典层（`dict`）：`NexaiDictAutoConfiguration` 暴露 `DictFrameworkUtils` Bean；`validation.InDict` 是 JSR-303 约束注解，委托 `InDictValidator`（单值）和 `InDictCollectionValidator`（集合）进行校验。
- 依赖方向：`excel` → `dict`（通过 `DictFrameworkUtils`）→ 外部 `nexai-common` 的 `DictDataCommonApi`；Web/Servlet 依赖标记为 `provided`，仅 `ExcelUtils` 使用，保证 starter 可被非 Web 项目复用。

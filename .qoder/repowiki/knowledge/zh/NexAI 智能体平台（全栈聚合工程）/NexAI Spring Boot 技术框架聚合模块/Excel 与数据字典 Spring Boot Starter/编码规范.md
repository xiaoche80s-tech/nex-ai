- 自定义 Excel 转换器统一实现 `cn.idev.excel.converters.Converter<Object>`，并通过重写 `supportJavaTypeKey` / `supportExcelTypeKey` 抛出 `UnsupportedOperationException` 交由注解驱动匹配。
- 字段级格式化通过声明式注解（如 `@DictFormat`、`@ExcelColumnSelect`）标注在实体字段上，由对应 Converter 在运行时读取注解元信息进行处理。
- 对可选外部依赖（如 `jakarta.servlet-api`、`nexai-spring-boot-starter-biz-ip`）一律声明为 `provided` / `optional`，仅在真正使用的类中引用，保持 starter 最小化耦合。
- 字典相关能力集中在 `DictFrameworkUtils` 静态工具类中，由 `NexaiDictAutoConfiguration` 在启动时注入 `DictDataCommonApi` 完成初始化，调用方无需感知 DI。
- 校验注解遵循 JSR-303 规范，通过 `@Constraint(validatedBy = {...})` 将单一注解委托给多个 Validator（如 `InDictValidator`、`InDictCollectionValidator`）分别处理标量与集合场景。

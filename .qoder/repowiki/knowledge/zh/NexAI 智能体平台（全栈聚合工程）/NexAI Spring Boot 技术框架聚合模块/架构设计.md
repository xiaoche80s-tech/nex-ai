本模块以 Maven POM 聚合形式组织，顶层 pom.xml 声明所有子模块并按依赖层次分组：基础层（common）→ 基础设施层（web、security、redis、mybatis、websocket）→ 横切增强层（monitor、protection、job、mq）→ 业务能力层（excel、tenant、data-permission、ip、test）。每个子模块遵循统一约定：核心逻辑放在 core 包，Spring 自动装配类放在 config 包，并通过 resources/META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports 注册 @AutoConfiguration 类，由 Spring Boot 在启动时按需加载；业务组件的 Maven artifactId 包含 biz 前缀以区分框架组件与业务组件。各 Starter 之间通过共享的 nexai-common 中的 POJO、异常体系、枚举及 biz 领域 API 契约进行解耦协作，例如 tenant、data-permission 均基于 mybatis 的拦截器扩展点注入 SQL 条件，protection/monitor/web 通过 filter/interceptor/aop 横切请求链路，mq/websocket/job 借助 redis 或 MQ 实现多节点广播与上下文透传。

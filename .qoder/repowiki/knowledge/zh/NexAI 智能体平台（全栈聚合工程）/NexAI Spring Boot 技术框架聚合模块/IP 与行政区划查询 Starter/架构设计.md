模块以 `com.gkht.ai.nexai.framework.ip.core` 为根包，按职责划分为三层：
- 数据模型层：`Area.java` 表示国家/省/市/区四级区域节点，通过 `parent`/`children` 双向引用构成树形结构，并使用 Jackson 的 `@JsonManagedReference`/`@JsonBackReference` 避免序列化循环；`AreaTypeEnum.java` 定义区域类型（国家、省份、城市、地区）。
- 资源加载层：启动时通过静态块从 classpath 资源文件加载数据——`IPUtils` 使用 `ResourceUtil.readBytes("ip2region.xdb")` 将 ip2region 索引载入内存并创建 `Searcher`；`AreaUtils` 读取 `area.csv` 构建 `Map<Integer, Area>` 并按行回填父子关系。
- 工具服务层：`IPUtils` 暴露 `getAreaId(String|long)` 与 `getArea(String|long)` 两个入口，内部委托 `AreaUtils.getArea(id)` 完成 ID→区域的映射；`AreaUtils` 额外提供 `parseArea(pathStr)`、`format(id, separator)`、`getByType(type, func)`、`getParentIdByType(id, type)` 等面向业务的查询与格式化方法。
依赖方向单向向下：工具类 → 模型/枚举 → 外部库（ip2region、Hutool CSV），不引入 Spring 自动装配，仅作为无状态工具 starter 被上层业务依赖。

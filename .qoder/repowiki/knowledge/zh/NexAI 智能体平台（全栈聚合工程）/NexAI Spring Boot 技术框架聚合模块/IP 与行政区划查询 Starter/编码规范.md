- 工具类统一使用 Lombok `@UtilityClass` + `@Slf4j` 声明为无状态单例工具，并通过类级 static 字段缓存解析结果（如 `SEARCHER`、`areas`）。
- 所有需要持久化数据的工具类在类加载时通过 `static { init(); }` 块完成资源一次性加载，并在日志中记录耗时。
- 区域模型采用自引用树结构（`parent`/`children`），并通过 Jackson `@JsonManagedReference`/`@JsonBackReference` 成对标注以避免循环序列化。
- 对外暴露的方法多为重载形式（如 `getAreaId(String ip)` 与 `getAreaId(long ip)`、`getArea(...)` 的多签名），以适配不同上游输入格式。
- 区域类型通过 `AreaTypeEnum` 枚举集中管理，并以 `type` 整型值与 `name` 描述共同标识，同时实现 `ArrayValuable<Integer>` 暴露类型数组。

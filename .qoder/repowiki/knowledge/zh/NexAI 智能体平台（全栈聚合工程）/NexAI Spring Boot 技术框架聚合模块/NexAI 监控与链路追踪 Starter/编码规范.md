- 自动装配类统一使用 `@AutoConfiguration` + `@ConditionalOnClass` + `@ConditionalOnProperty` 三件套实现可选功能开关。
- 对外暴露的配置项集中通过 `@ConfigurationProperties` 绑定到 `TracerProperties`，并以 `nexai.*` 作为前缀命名空间。
- 需要第三方 SDK 的功能均将对应依赖声明为 `optional`，并通过 `@ConditionalOnClass` 判断是否生效，避免强耦合。
- 业务埋点采用注解+切面模式：自定义 `@BizTrace` 注解配合 `@Aspect` 切面完成 Span 生命周期管理，异常统一走 `TracerFrameworkUtils.onError` 上报。
- HTTP 链路透传通过 `OncePerRequestFilter` 实现，并使用 `FilterRegistrationBean` 显式指定 `order` 以保证执行顺序。

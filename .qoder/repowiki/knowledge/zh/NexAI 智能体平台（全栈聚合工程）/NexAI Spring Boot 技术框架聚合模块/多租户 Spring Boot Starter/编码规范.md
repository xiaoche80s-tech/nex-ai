- 所有跨组件共享的租户上下文统一通过 `TenantContextHolder` 的 `TransmittableThreadLocal` 存取，并在 finally 块中恢复或清理。
- 可选依赖（Kafka、RabbitMQ、RocketMQ、Quartz）采用内部静态 `@Configuration` + `@ConditionalOnClass` 的方式条件化注册，避免无依赖时报错。
- 需要忽略多租户的场景通过 `@TenantIgnore` 注解声明，并在数据库层、AOP 层、Web 安全过滤层多处一致判断该注解。
- Web 层拦截器通过 `FilterRegistrationBean` + `WebFilterOrderEnum` 显式指定执行顺序，确保上下文先于安全校验建立。
- 配置项集中在 `TenantProperties` 中以 `@ConfigurationProperties(prefix = "nexai.tenant")` 绑定，并提供空集合默认值以便按需扩展白名单。

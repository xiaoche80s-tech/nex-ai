模块以 `NexaiTenantAutoConfiguration`（注册于 `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports`）为唯一入口，按功能域划分为多个子包：`config` 暴露 `TenantProperties` 配置类并集中装配所有 Bean；`core/context` 使用 `TransmittableThreadLocal` 维护当前线程的 `tenantId` 与忽略标志；`core/db` 通过 MyBatis Plus 的 `TenantLineInnerInterceptor` + `TenantDatabaseInterceptor` 在 SQL 层自动拼接 `tenant_id`，并以 `TenantBaseDO` 基类标记需隔离的实体；`core/web` 提供 `TenantContextWebFilter`/`TenantSecurityWebFilter`/`TenantVisitContextInterceptor` 从请求头解析租户上下文；`core/aop` 通过 `@TenantIgnore` 注解与 Aspect 支持方法级忽略；`core/mq` 针对 Redis/RabbitMQ/Kafka/RocketMQ 分别提供消息发送/消费钩子以透传租户信息；`core/redis` 用 `TenantRedisCacheManager` 重写默认 `RedisCacheManager` 并在 key 中追加租户前缀；`core/job` 对 Quartz 任务进行租户上下文注入。各 MQ 与 Job 相关配置均以内部静态 `@Configuration` + `@ConditionalOnClass` 形式按需加载，避免引入可选依赖时的启动失败。依赖方向单向向下：配置 → Web/DB/AOP/MQ/Redis/Job 各层均读取 `TenantContextHolder`，不反向依赖业务代码。

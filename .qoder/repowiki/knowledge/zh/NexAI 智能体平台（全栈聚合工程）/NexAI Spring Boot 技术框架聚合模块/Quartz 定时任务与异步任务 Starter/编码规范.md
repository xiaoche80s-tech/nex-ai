- 通过 `@AutoConfiguration` + `META-INF/spring/...AutoConfiguration.imports` 双注册方式暴露 Quartz 与 Async 两个独立能力。
- 所有 Quartz JobData 键统一集中在 `JobDataKeyEnum` 中以字符串常量形式传递，避免魔法字符串散落。
- `SchedulerManager` 每个公开方法首行调用 `validateScheduler()` 检查 `scheduler` 是否为 null，未启用时统一抛出框架级异常。
- `JobHandlerInvoker` 使用 `@DisallowConcurrentExecution` 与 `@PersistJobDataAfterExecution` 注解保证单实例串行执行且数据持久化。
- 任务执行生命周期遵循“创建日志 → 执行业务 → 异步更新结果 → 按重试策略抛异常或成功返回”的四步模板模式。
- 对外扩展点采用接口隔离：`JobHandler` 供业务实现任务逻辑，`JobLogFrameworkService` 供外部实现日志持久化，starter 内部不耦合具体实现。

模块以 Spring Boot AutoConfiguration 为入口，通过 `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 注册两个自动装配类：`NexaiQuartzAutoConfiguration`（启用 `@EnableScheduling` 并注入可选的 `Scheduler` 到 `SchedulerManager`）和 `NexaiAsyncAutoConfiguration`（启用 `@EnableAsync` 并通过 `BeanPostProcessor` 给 `ThreadPoolTaskExecutor`/`SimpleAsyncTaskExecutor` 注入 `TtlRunnable` 装饰器以透传 MDC/TransmittableThreadLocal）。核心分层清晰：
- `core/handler`：定义 `JobHandler` 接口（`execute(String)`），由业务实现；`JobHandlerInvoker` 继承 `QuartzJobBean` 作为统一执行入口，负责读取 JobData、调用处理器、记录日志、处理重试。
- `core/scheduler`：`SchedulerManager` 封装对 Quartz `Scheduler` 的增删改查与立即触发，使用 `jobHandlerName` 同时作为 `JobDetail` 与 `Trigger` 的唯一标识。
- `core/service`：`JobLogFrameworkService` 是日志落库的 SPI 接口，由外部 starter 实现，解耦持久化细节。
- `core/enums/util`：`JobDataKeyEnum` 集中声明 JobData 键，`CronUtils` 提供表达式工具。
依赖方向单向：配置层 → 调度层 → 执行层 → 日志 SPI，对外仅暴露 `SchedulerManager` 与 `JobHandler` 两个扩展点。

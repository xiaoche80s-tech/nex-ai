模块以 `NexaiWebSocketAutoConfiguration` 为唯一自动配置入口（注册于 `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports`），通过 `@EnableWebSocket` 与 `WebSocketConfigurer` 将 `JsonWebSocketMessageHandler` 挂载到可配置的 `/ws` 路径，并注入 `LoginUserHandshakeInterceptor` 完成握手鉴权。

内部按职责分层：
- `config`：`WebSocketProperties` 暴露 `nexai.websocket.*` 配置项；`NexaiWebSocketAutoConfiguration` 内嵌多个 `@ConditionalOnProperty(sender-type=...)` 子配置类，按需装配 local/redis/kafka/rabbitmq/rocketmq 五种消息发送器及其对应的 Consumer。
- `core/handler`：`JsonWebSocketMessageHandler` 继承 `TextWebSocketHandler`，解析 `JsonWebSocketMessage` 后按 `type` 路由到注册的 `WebSocketMessageListener` 列表。
- `core/listener`：定义业务侧扩展点 `WebSocketMessageListener<T>`，由框架在启动时收集并建立 type→listener 映射。
- `core/message`：统一消息帧 `JsonWebSocketMessage`（type + content）。
- `core/session`：`WebSocketSessionManagerImpl` 用 `ConcurrentHashMap` + `CopyOnWriteArrayList` 维护 sessionId→session 及 userType→userId→sessions 索引，并在查询时结合 `TenantContextHolder` 做租户隔离。
- `core/security`：`LoginUserHandshakeInterceptor` 从握手请求提取 `LoginUser` 存入 session 属性；`WebSocketAuthorizeRequestsCustomizer` 自定义安全授权规则。
- `core/sender`：`WebSocketMessageSender` 接口定义 send(sendObject) 重载，`AbstractWebSocketMessageSender` 封装统一的 session 查找、JSON 序列化与发送逻辑；各后端实现（local/redis/kafka/rabbitmq/rocketmq）仅关注跨进程投递，Consumer 再回调同一 sender 把消息落回本地 session。

依赖方向单向：sender → session manager → handler → listener；可选依赖 mq starter 与 security/biz-tenant starter，通过 `provided` 或 `optional` 保持 starter 的松耦合。

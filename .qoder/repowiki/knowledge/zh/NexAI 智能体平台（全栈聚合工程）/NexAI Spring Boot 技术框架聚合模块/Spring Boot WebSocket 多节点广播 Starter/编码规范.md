- 所有可插拔的消息发送器均实现 `WebSocketMessageSender` 接口，并由 `AbstractWebSocketMessageSender` 统一处理 session 查找、JSON 序列化与异常日志，子类只需实现跨进程投递细节。
- 多后端通过嵌套 `@Configuration` 类 + `@ConditionalOnProperty(prefix = "nexai.websocket", name = "sender-type", havingValue = "...")` 实现运行时切换，每个后端同时装配 Sender 与对应的 Consumer Bean。
- 业务消息采用 `JsonWebSocketMessage` 帧结构（type + content），handler 根据 type 分发到同名的 `WebSocketMessageListener<T>`，监听器通过泛型参数声明消息体类型。
- 会话管理使用 `ConcurrentHashMap` + `CopyOnWriteArrayList` 保证并发安全，并按 userType→userId 二级索引存储，查询时结合 `TenantContextHolder` 做租户过滤。
- 配置项集中放在 `WebSocketProperties` 上，使用 `@ConfigurationProperties("nexai.websocket")` 绑定并以 `@Validated` 校验必填字段。

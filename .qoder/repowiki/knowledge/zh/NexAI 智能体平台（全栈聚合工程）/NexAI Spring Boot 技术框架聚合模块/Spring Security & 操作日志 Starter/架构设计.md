模块以 Spring Boot 3 AutoConfiguration 形式暴露，通过 `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 注册三个自动配置类：`NexaiSecurityAutoConfiguration`（装配 `TokenAuthenticationFilter`、`AuthenticationEntryPointImpl`、`AccessDeniedHandlerImpl`、`BCryptPasswordEncoder`、`SecurityFrameworkService` 及自定义 `SecurityContextHolderStrategy`）、`NexaiWebSecurityConfigurerAdapter`（继承 WebSecurityConfigurerAdapter 完成 URL 级安全规则）和 `NexaiOperateLogConfiguration`（启用并注入 mzt-logapi 的 `ILogRecordService`）。核心代码按职责分层：`config` 负责配置与属性绑定（`SecurityProperties`），`core/filter` 中的 `TokenAuthenticationFilter` 从请求头/参数取 token，调用远端 `OAuth2TokenCommonApi.checkAccessToken` 校验后构建 `LoginUser` 并写入上下文；`core/service` 暴露 `SecurityFrameworkService` 接口及其实现，封装角色/权限/Scope 判断逻辑；`core/context` 使用 `TransmittableThreadLocalSecurityContextHolderStrategy` 替换默认策略以支持异步线程池传递；`core/handler` 统一返回 `GlobalExceptionHandler` 风格的 `CommonResult`；`operatelog` 子包独立于 security，复用同一 starter 对外提供注解式操作日志。依赖方向单向向外：starter 仅依赖 `framework-common`、`framework-web` 等基础模块，不反向被业务模块直接引用内部实现。

- 所有可装配组件通过 `@AutoConfiguration` + `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 集中声明，避免手写 `spring.factories`。
- 安全相关 Bean（过滤器、处理器、编码器、服务）统一在 `NexaiSecurityAutoConfiguration` 中以 `@Bean` 方法暴露，便于集中管理与顺序控制。
- 鉴权失败与无权限场景统一通过 `AuthenticationEntryPointImpl` / `AccessDeniedHandlerImpl` 返回 `GlobalExceptionHandler` 处理后的 `CommonResult` JSON，而非传统页面跳转。
- 登录态信息封装为 `LoginUser` 对象并通过 `SecurityFrameworkUtils` 存取，结合 `TransmittableThreadLocalSecurityContextHolderStrategy` 保证跨线程传递。
- 外部扩展点（如权限校验、日志记录）以接口形式定义（`SecurityFrameworkService`、`ILogRecordService`），由 starter 提供默认实现并通过 `@Primary` 或 `@Bean` 注入。

- 每个子能力独立包结构：`config` 放 `@AutoConfiguration`，`core/annotation` 放注解，`core/aop` 放 Aspect，`core/keyresolver` 定义策略接口及多种实现，`core/redis` 封装 RedisDAO。
- 配置类统一标注 `@AutoConfiguration(after = NexaiRedisAutoConfiguration.class)`，保证在 Redis 自动配置之后加载。
- Key 解析采用策略模式：注解中通过 `keyResolver` 属性指定实现类，并由配置类将全部实现以 `List<XxxKeyResolver>` 注入到 Aspect 中按需选用。
- 注解设计保持一致：均支持 `time/timeUnit` 超时、`message` 自定义提示、`keyArg` 表达式参数以及可插拔的 KeyResolver。
- 可选依赖通过 `@ConditionalOnClass` 包裹（如 lock4j），避免未引入第三方库时报错。

模块以 Spring Boot Starter 形式组织，通过 `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 自动注册四个子能力的配置类：`NexaiRateLimiterConfiguration`、`NexaiIdempotentConfiguration`、`NexaiLock4jConfiguration`、`NexaiApiSignatureAutoConfiguration`。每个子能力遵循统一分层：`config` 下定义 `@AutoConfiguration` 装配 Bean；`core/annotation` 暴露用户可见注解（`@RateLimiter`、`@Idempotent`、`@ApiSignature`）；`core/aop` 中 Aspect 拦截注解并执行业务逻辑；`core/keyresolver` 采用策略接口 + `impl/*Resolver` 多实现（如 Default/User/ClientIp/ServerNode/Expression），由配置类注入 `List<XxxKeyResolver>` 供 Aspect 按优先级选择；`core/redis` 封装 RedisDAO（基于 `RedissonClient` 或 `StringRedisTemplate`）用于状态持久化。依赖方向单向：AOP → KeyResolver → RedisDAO，且所有配置均声明 `after = NexaiRedisAutoConfiguration.class`，确保 Redis 先就绪。`lock4j` 子模块使用 `@ConditionalOnClass("com.baomidou.lock.annotation.Lock4j")` 做可选依赖，仅在引入 `lock4j-redisson-spring-boot-starter` 时生效。

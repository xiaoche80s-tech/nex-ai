模块以 Maven starter jar 形式发布（artifactId: nexai-spring-boot-starter-test），依赖 nexai-common、nexai-spring-boot-starter-mybatis、nexai-spring-boot-starter-redis 以及 spring-boot-starter-test、mockito-inline、h2、jedis-mock、podam。

内部按职责分为三层：
- config/：定义测试专用配置类。RedisTestConfiguration 通过 jedis-mock 启动内嵌 RedisServer；SqlInitializationTestConfiguration 复制 Spring 的 DataSourceInitializationConfiguration 逻辑，确保在延迟加载模式下仍能执行 schema/data SQL。
- core/ut/：提供可继承的测试基类。BaseDbUnitTest 仅装配数据源与 MyBatis（H2 + Druid + MyBatis-Plus + MyBatis-Plus-Join）；BaseRedisUnitTest 仅装配 Redis（DataRedisAutoConfiguration + NexaiRedisAutoConfiguration + Redisson）；BaseDbAndRedisUnitTest 组合两者；BaseMockitoUnitTest 仅提供 MockitoExtension 扩展。所有 SpringBootTest 基类统一使用 @ActiveProfiles("unit-test") 并关闭 webEnvironment。
- core/util/：提供 AssertUtils、RandomUtils 等测试辅助工具。

依赖方向单向向下：base 类 → config → 框架各 starter 的自动配置类；不反向依赖业务代码，保证被任意模块 test 包直接继承使用。

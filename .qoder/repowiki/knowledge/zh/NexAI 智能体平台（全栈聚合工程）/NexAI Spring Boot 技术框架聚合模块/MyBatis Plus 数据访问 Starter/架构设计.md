模块以 Spring Boot AutoConfiguration 为核心入口，通过 `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 注册三个配置类：`NexaiDataSourceAutoConfiguration`（启用事务管理、Druid 监控并过滤广告脚本）、`NexaiMybatisAutoConfiguration`（在 MyBatisPlusAutoConfiguration 之前执行，配置 MapperScan、分页拦截器、MetaObjectHandler、按 DbType 动态选择 IKeyGenerator、Jackson3TypeHandler）以及 `NexaiTranslateAutoConfiguration`（Easy-Trans 集成）。内部按职责划分为四个子包：`datasource` 负责连接池与多数据源常量/过滤器；`mybatis/core` 提供基础实体 `BaseDO`、扩展 Mapper `BaseMapperX`（继承 MPJBaseMapper，封装分页、批量插入、FOR UPDATE、selectFirstOne 等常用方法）、查询包装器扩展（LambdaQueryWrapperX/MPJLambdaWrapperX/QueryWrapperX）、字段自动填充处理器 `DefaultDBFieldHandler`、数据库类型枚举与 JDBC 工具类；`translate` 暴露翻译工具。依赖方向单向向下：配置类 → core 工具/处理器 → 第三方库（MyBatis Plus、dynamic-datasource、druid、yulichang），并通过 optional 声明多种数据库驱动以支持运行时按需加载。

- 所有公共 Bean 通过 `@AutoConfiguration` 类集中注册，并按功能拆分为 datasource、mybatis、translate 三个独立配置类。
- 实体基类 `BaseDO` 统一声明 createTime/updateTime/creator/updater/deleted 字段并使用 `@TableField(fill=...)` + `MetaObjectHandler` 自动填充。
- 对业务无感知的通用查询能力以 default 方法形式追加到 `BaseMapperX<T>`，调用方直接继承该接口即可获得分页、批量、FOR UPDATE 等方法。
- 数据库方言差异通过 `JdbcUtils.getDbType()` + `DbTypeEnum` 判断后分支处理（如 SQL Server 特殊走循环插入），避免在业务代码中散落 if-else。
- 可选依赖的数据库驱动在 pom.xml 中以 `<optional>true</optional>` 声明，运行时根据实际连接 URL 动态选择对应 KeyGenerator。

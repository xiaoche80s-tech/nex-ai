- 通过继承 `AbstractRedisChannelMessage` / `AbstractRedisStreamMessage` 定义消息类型，并在基类中暴露 channel/streamKey/group 等元信息供模板与监听器读取。
- 消费者监听器统一继承 `AbstractRedisChannelMessageListener<T>` 或 `AbstractRedisStreamMessageListener<T>`，利用泛型反射推断消息类型，并重写 `onMessage(T message)` 实现业务处理。
- 发送与消费流程均通过 `RedisMessageInterceptor` 链进行横切增强，before 正序执行、after 倒序执行，保证日志、埋点、幂等等横切逻辑可插拔。
- 自动配置类使用 `@AutoConfiguration(after = NexaiRedisAutoConfiguration.class)` 明确依赖顺序，并使用 `@ConditionalOnBean` / `@ConditionalOnClass` 实现按需装配，避免不必要的 Bean 创建。
- Stream 消费采用 `autoAcknowledge=false` 的手动 ack 模式，成功处理后显式调用 `acknowledge`，配合 pending 重投任务实现至少一次语义。
- 定时任务（pending 重发、消息清理）统一通过 `@Scheduled(cron = ...)` + Redisson `RLock` 分布式锁实现多实例安全执行。

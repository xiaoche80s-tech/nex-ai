本模块以 Maven jar 形式作为框架最底层的公共依赖，被上层各业务模块引用。内部按职责划分为五个层次：
- `pojo/`：统一返回体 `CommonResult<T>`、分页参数/结果 `PageParam/PageResult/SortablePageParam`、排序字段等跨模块共享的数据载体。
- `exception/`：定义 `ErrorCode`、全局错误码常量 `GlobalErrorCodeConstants`、范围划分 `ServiceErrorCodeRange`、业务异常 `ServiceException` 与 `ServerException`，并通过 `ServiceExceptionUtil` 提供格式化能力；`CommonResult.checkError()` 与该异常体系联动实现“返回值即异常”的统一错误传播。
- `validation/`：基于 Jakarta Validation 自定义约束注解（`InEnum`、`Mobile`、`Telephone`）及对应 Validator，配合 `core.ArrayValuable` 接口实现枚举值域校验。
- `util/`：按领域划分的纯静态工具包（collection/date/http/io/json/servlet/string/spring/number/object/cache/monitor），其中 `json.JsonUtils` 封装了基于 `tools.jackson` 的 ObjectMapper，并注册 `LocalDateTime` 时间戳序列化器，支持通过 `init(ObjectMapper)` 注入 Spring Bean 覆盖默认实例。
- `biz/`：定义跨模块调用的领域 API 契约（`system/*` 下的 DictDataCommonApi、OperateLogCommonApi、OAuth2TokenCommonApi、PermissionCommonApi、TenantCommonApi；`infra/logger` 下的 ApiAccessLog/ApiErrorLog CommonApi），每个子域包含 `dto/` 请求响应对象与一个纯 Java 接口，由具体模块实现，从而解耦调用方与被调用方的部署边界。
依赖方向严格单向：`biz` → `pojo/exception/validation/util/enums/core`，不反向依赖任何业务实现；所有第三方依赖在 `pom.xml` 中声明为 `provided` 或仅引入必要运行时库（如 hutool-all、fastjson、opentelemetry-api、easy-trans-anno），保证该模块可被任意 Spring Boot 应用直接复用。

- 每个子能力采用 `config/*AutoConfiguration` + `core/*` 的分层结构，配置类负责 Bean 注册与属性绑定，核心实现集中在 core 包。
- 通过自定义注解（如 `@ApiAccessLog`、`@ApiEncrypt`、`@DesensitizeBy` 及其派生注解）声明式开启功能，配合拦截器/过滤器/序列化器在运行时执行。
- 所有自动配置类均标注 `@AutoConfiguration` 并在 `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 中显式列出，避免组件扫描。
- 可插拔处理器通过接口抽象（如 `DesensitizationHandler`、`XssCleaner`）并提供默认实现，用户可替换或扩展。
- Filter 统一通过 `FilterRegistrationBean` + `WebFilterOrderEnum` 常量注册，保证执行顺序可控且可被覆盖。
- 全局异常处理集中在 `GlobalExceptionHandler`，按异常类型拆分为独立的 `@ExceptionHandler` 方法，最终统一返回 `CommonResult`。

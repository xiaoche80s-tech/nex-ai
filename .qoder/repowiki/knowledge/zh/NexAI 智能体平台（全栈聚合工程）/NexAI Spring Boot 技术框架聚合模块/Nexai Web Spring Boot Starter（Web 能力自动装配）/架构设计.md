模块以 Spring Boot 3 的 `@AutoConfiguration` + `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 作为入口，集中注册 7 个独立子能力：web（全局异常处理器、响应体统一包装、CORS/RequestBody 缓存 Filter、RestTemplate）、apilog（基于注解+拦截器的访问日志）、desensitize（Jackson 序列化期脱敏，支持 base/regex/slider 三类处理器）、encrypt（基于 Filter 的请求解密与响应加密）、xss（Jsoup 清洗 + Filter + JSON 反序列化器）、swagger（Knife4j/OpenAPI 定制）、banner（启动 Banner）。每个子能力遵循统一的 `config/*AutoConfiguration` + `core/*` 分层：配置类通过 `@EnableConfigurationProperties` 绑定 `*Properties`，核心逻辑放在 `core` 包下，注解定义在 `core.annotation`，处理器/过滤器在 `core.handler` 或 `core.filter`。依赖方向单向指向 `nexai-common`（如 `CommonResult`、`ServiceException`、`ApiErrorLogCommonApi`），各子能力之间无相互依赖，通过 Starter 聚合对外暴露。

- 每个 Starter 采用 core/config 双层结构：core 存放核心封装，config 存放 @AutoConfiguration 配置类。
- 所有自动装配能力通过 resources/META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports 文件注册，而非 spring.factories。
- 业务相关 Starter 的 Maven artifactId 统一包含 biz 前缀（如 biz-tenant、biz-data-permission、biz-ip），以区别于通用框架组件。
- 跨模块共享的 POJO、异常、枚举、校验注解统一收敛到 nexai-common，其他 Starter 仅依赖其 API 而不直接耦合实现。
- 横切能力（限流、幂等、签名、监控、租户、数据权限）统一通过 AOP / Filter / Interceptor / MyBatis 拦截器 的方式无侵入接入。

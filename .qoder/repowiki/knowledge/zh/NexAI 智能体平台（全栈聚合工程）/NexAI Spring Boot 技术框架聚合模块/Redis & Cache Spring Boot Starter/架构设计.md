模块以 Spring Boot AutoConfiguration 形式对外暴露能力，通过 `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 注册两个自动装配类：`NexaiRedisAutoConfiguration` 在 `RedissonAutoConfigurationV4` 之前执行，定义使用 String Key + JSON Value 序列化的 `RedisTemplate<String, Object>` Bean；`NexaiCacheAutoConfiguration` 启用 `@EnableCaching`，绑定 `CacheProperties` 与 `NexaiCacheProperties`，构建 `RedisCacheConfiguration`（统一冒号分隔的前缀策略、JSON 序列化、TTL 与 null 值策略），并创建基于 `RedisCacheWriter.nonLockingRedisCacheWriter` 的 `TimeoutRedisCacheManager`，开启事务感知使 `@CacheEvict/@CachePut` 延迟到 afterCommit。核心扩展点 `TimeoutRedisCacheManager` 继承 `RedisCacheManager`，重写 `createRedisCache`，解析形如 `cacheName#ttl[d|h|m|s]` 的命名约定为 `Duration` 后覆盖默认 TTL。依赖方向单向指向 `nexai-common`、Spring Data Redis、Redisson starter 与 Jackson，不反向依赖业务模块。

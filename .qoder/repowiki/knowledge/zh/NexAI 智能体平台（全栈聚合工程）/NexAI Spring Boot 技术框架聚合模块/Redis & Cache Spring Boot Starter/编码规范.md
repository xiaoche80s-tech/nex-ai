- 自动装配类使用 `@AutoConfiguration` 注解并通过 `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 集中声明，而非 `@ComponentScan`。
- 对第三方自动装配进行顺序控制，使用 `before = RedissonAutoConfigurationV4.class` 确保自定义 `RedisTemplate` 优先于 Redisson 默认装配生效。
- 序列化统一通过静态方法 `buildRedisSerializer()` 返回 `RedisSerializer.json()`，并在 `RedisTemplate` 与 `RedisCacheConfiguration` 两处复用。
- 缓存 key 前缀统一采用单冒号 `:` 分隔（`cacheName + COLON`），避免双冒号导致的可视化工具显示问题。
- 通过继承 `RedisCacheManager` 并重写 `createRedisCache` 的方式扩展缓存行为，而非替换整个 Manager，保持与 Spring Cache 协议兼容。

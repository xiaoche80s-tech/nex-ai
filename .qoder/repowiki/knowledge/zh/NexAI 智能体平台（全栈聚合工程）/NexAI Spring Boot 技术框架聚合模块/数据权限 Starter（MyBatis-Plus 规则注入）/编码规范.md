- 数据权限规则统一实现 `DataPermissionRule` 接口，通过 `getTableNames()` 声明作用表、`getExpression()` 返回 JSqlParser 表达式片段。
- 规则选择由 `DataPermissionRuleFactoryImpl` 集中完成，业务代码不直接持有规则列表，而是通过 `mappedStatementId` 或注解上下文获取。
- AOP 拦截器采用「入栈-执行-finally 出栈」模式维护线程局部上下文，并使用 `ConcurrentHashMap` + `MethodClassKey` 缓存注解解析结果。
- SQL 条件拼接统一通过 JSqlParser 表达式对象（`AndExpression`、`OrExpression`、`InExpression`、`EqualsTo` 等）组合，而非字符串拼接。
- 自动配置通过 `@AutoConfiguration` 类集中注册 Bean，并由 `META-INF/spring/...AutoConfiguration.imports` 清单文件声明，遵循 Spring Boot 3 自动装配约定。

脚本按用途垂直切分为独立子目录，彼此无代码依赖，仅通过环境变量或约定路径协作：
- `shell/deploy.sh`：JVM 应用一键部署脚本，封装 backup→stop→transfer→start→healthCheck 五步流程，默认目标为 `/work/projects/nexai-server`，通过 `HEALTH_CHECK_URL` 轮询 Spring Boot Actuator。
- `jenkins/Jenkinsfile`：Jenkins Pipeline 定义检出→替换配置文件→`mvn clean package`→拷贝 jar 并调用 `deploy.sh` 的完整发布流水线，凭据以 Jenkins Credentials ID 注入。
- `docker/docker-compose.yml`：编排 MySQL 8、Redis、后端 `server`、前端 `admin` 四服务，使用 `.env` 变量注入数据库连接与 JVM 参数；`sql/mysql/ruoyi-vue-pro.sql` 作为初始化数据卷挂载。
- `smoke/`：M1 MVP 验收冒烟套件——`m1-acceptance.sh` 驱动登录、渠道创建+连通性测试、模型登记、规格发布、两轮 SSE 对话及流中断幂等重发；`fake-openai-server.py` 基于标准库实现 OpenAI 兼容 SSE mock；`sse-consumer.py` 解析调试会话事件流并断言类型序列、文本与 token 用量。
- `livekit-poc/`：LiveKit Server PoC 验证脚本，用 Python 内联生成 HS256 JWT 管理/客户端 Token，通过 Twirp HTTP 调用 CreateRoom/ListRooms/DeleteRoom，`docker-compose.yml` + `livekit.yaml` 拉起服务。
- `idea/http-client.env.json`：IntelliJ HTTP Client 多环境（local/gateway）变量文件，供 API 调试。
依赖方向单向：脚本 → 外部系统（MySQL/Redis/K8s/DockerHub/GitHub），模块内部各子目录互不引用。

- Shell 脚本统一以 `set -e`（或 `set -euo pipefail`）开头，并通过函数封装 backup/stop/start/healthCheck 等步骤，主流程顺序调用。
- 所有可配置项（端口、URL、凭据、租户等）均通过环境变量提供默认值（`${VAR:-default}`），避免硬编码。
- 冒烟脚本采用「step」分步打印 + `die` 统一失败退出，配合 `trap cleanup EXIT` 保证临时进程/文件清理。
- SSE 事件消费统一交由独立的 Python 解析器（`sse-consumer.py`）处理，bash 仅负责发起 curl 请求并传递期望断言参数。
- OpenAI 兼容 mock 服务与真实模型通过同一接口（`/v1/chat/completions` 或 `/chat/completions`）暴露，使冒烟脚本无需区分后端实现。

- 本地开发：`docker compose -f script/docker/docker-compose.yml up`，需准备 `script/docker/sql/mysql/ruoyi-vue-pro.sql`。
- 部署到服务器：Jenkins 触发后自动执行 `deploy.sh`；也可手动 `bash script/shell/deploy.sh`，需提前将 `build/nexai-server.jar` 放入 `/work/projects/nexai-server/build`。
- 运行 MVP 冒烟：`bash script/smoke/m1-acceptance.sh`（默认 mock 模式，无需凭据）；真实模型模式需 `export M1_SMOKE_MODE=real M1_AI_BASE_URL=... M1_AI_API_KEY=... M1_AI_MODEL=...`。
- LiveKit PoC：`cd script/livekit-poc && docker compose up -d && bash verify.sh`，浏览器访问输出中的 meet.livekit.io 链接。

- 每个领域（部门、岗位）均遵循 API 接口 + Impl、Controller + VO、Service + ServiceImpl 的对称分层结构，并按 `dto`、`vo` 子包隔离传输对象。
- Controller 方法统一返回 `CommonResult<T>`，通过 `BeanUtils.toBean` 将 DO 转换为 VO 后再封装返回。
- 所有写操作与敏感读操作通过 `@PreAuthorize("@ss.hasPermission('system:{entity}:{action}')")` 声明式授权，动作粒度细化到 create/update/delete/query/export。
- Service 接口中常用聚合能力（如 `getDeptMap`、`getChildDeptList`）以 `default` 方法提供基于列表查询的默认实现，减少重复代码。
- 对外暴露的只读查询（如 `list-all-simple`/`simple-list`）通过过滤 `CommonStatusEnum.ENABLE` 仅返回启用项，用于前端下拉选项。

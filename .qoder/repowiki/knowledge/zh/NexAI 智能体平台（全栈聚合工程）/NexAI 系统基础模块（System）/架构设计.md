本模块按领域子域划分为多个并列子模块（auth_and_oauth2、user_and_permission、permission_management、tenant_management、dept_and_dict、dict_data、social_login、logging_and_notice、notice_board、mail_service、sms_service、notify_service），每个子域遵循相同的四层结构：`controller/admin` 暴露管理后台 HTTP 接口、`api` 定义供其他模块调用的远程 API（含 `*Api` 接口与 `*ApiImpl` 实现）、`service` 承载业务逻辑、`dal/dataobject` + `dal/mysql/*Mapper` 映射数据库表，并通过 `convert` 完成 VO/DTO/DO 转换。

跨子域的协作方式包括：
- 通过 `framework_infrastructure` 提供的统一配置（验证码、JustAuth、操作日志解析、数据权限、Web 配置）和全局常量枚举（ErrorCodeConstants、LogRecordConstants、DictTypeConstants）保持行为一致；
- 通过 `mq` 目录下的 Spring Event 机制在邮件发送、短信发送、用户资料变更等场景进行异步解耦；
- 通过 `job` 中的 Quartz 定时任务（如 TokenCleanJob）清理过期令牌；
- 通过 `redis` 缓存 OAuth2 访问令牌并集中维护 RedisKeyConstants。

所有子模块共享同一包根 `com.gkht/ai/nexai/module/system`，由上层应用装配启动，对外仅暴露 `api` 与 `controller` 两个入口，内部 service/dal 不直接暴露给外部模块。

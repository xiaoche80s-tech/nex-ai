模块按三层划分：`api/notify` 定义跨模块调用的 `NotifyMessageSendApi` 接口及其实现，仅暴露 `sendSingleMessageToAdmin` / `sendSingleMessageToMember` 两个方法，由 `NotifyMessageSendApiImpl` 委派给 `NotifySendService`；`controller/admin/notify` 提供管理后台 REST 接口，`NotifyMessageController` 负责站内信的查询、分页、已读标记与未读数统计，`NotifyTemplateController` 负责模板的 CRUD、分页、启用列表以及通过模板直接发送站内信；`service/notify` 是核心业务层，拆分为 `NotifyMessageService`（消息持久化与状态管理）、`NotifyTemplateService`（模板缓存读取、内容格式化）和 `NotifySendService`（发送编排），其中 `NotifySendServiceImpl` 串联模板校验、参数校验、内容渲染后调用 `NotifyMessageService.createNotifyMessage` 完成落库。依赖方向自下而上为 controller → service → api impl，service 之间通过接口解耦，DAL 层（DO）位于本模块之外被引用。

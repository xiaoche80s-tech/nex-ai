- Controller 使用 `@RestController` + `@RequestMapping("/system/xxx")` 分组，并以 `@Tag`、`@Operation`、`@Parameter` 标注接口元数据。
- 所有写操作和查询接口均通过 `@PreAuthorize("@ss.hasPermission('system:xxx:create|update|delete|query')")` 声明权限点。
- 请求参数使用 `@Valid` 校验，响应统一包装为 `CommonResult.success(...)`。
- DO 到 VO 的转换统一通过 `BeanUtils.toBean(...)` 完成，避免在 Controller 中手写映射。
- Service 接口采用“接口+Impl”形式，并在接口中以 default 方法封装通用参数（如按用户类型分发）。
- 外部调用入口集中在 `api/mail` 下的 `*Api` 接口与 `*ApiImpl`，内部 Controller 不直接暴露给外部系统。

模块按三层划分：`api/mail` 暴露跨模块调用的 `MailSendApi` 接口及 `MailSendApiImpl` 实现，仅对外提供 `sendSingleMailToAdmin` / `sendSingleMailToMember` 两个入口；`controller/admin/mail` 下按业务域拆分为 `MailAccountController`、`MailTemplateController`、`MailLogController`，每个 Controller 对应一组 VO（`vo/account`、`vo/template`、`vo/log`），通过 `@PreAuthorize` 进行权限控制并统一返回 `CommonResult`；`service/mail` 定义 `MailAccountService`、`MailTemplateService`、`MailLogService`、`MailSendService` 四个服务接口及其 Impl，其中 `MailSendService` 在接口内以 default 方法区分 Admin/Member 用户类型，并通过 `doSendMail(MailSendMessage)` 暴露 MQ Consumer 入口，实际发送逻辑下沉到下游实现。依赖方向严格自上而下：Controller → Service → DAL（DO 位于 `module.system.dal.dataobject.mail`），API 层直接依赖 Service 而不经过 Controller。

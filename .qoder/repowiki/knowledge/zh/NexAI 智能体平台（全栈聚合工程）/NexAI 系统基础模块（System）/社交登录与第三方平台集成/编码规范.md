- 对外 API 以 *Api 接口加 *ApiImpl 实现类形式暴露，实现类通过 @Service 注册并委托给对应 Service。
- Controller 方法统一返回 CommonResult<T>，并使用 @Valid 校验请求体、@PreAuthorize 进行权限控制。
- 请求响应对象分层：Controller 使用 vo/* 包下的 VO，API 层使用 dto/* 包下的 DTO，两者通过 BeanUtils.toBean 转换。
- 平台差异化能力通过注释区块在接口中分组声明，如微信小程序独有方法集中放置。
- Service 层对第三方平台回调或异常场景通过抛出 ServiceException 表达业务错误。

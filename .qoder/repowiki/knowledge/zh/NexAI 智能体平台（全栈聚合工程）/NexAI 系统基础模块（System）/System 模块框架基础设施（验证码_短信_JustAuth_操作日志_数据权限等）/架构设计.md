本模块位于 `com.gkht.ai.nexai.module.system.framework`，按功能域拆分为多个子包：
- `captcha/`：基于 anji-captcha 扩展图片文字验证码（`PictureWordCaptchaServiceImpl`），并通过 `RedisCaptchaServiceImpl` 实现 Redis 缓存；由 `NexaiCaptchaConfiguration` 装配。
- `sms/`：以 `SmsClient` 接口 + `AbstractSmsClient` 模板方法抽象各厂商实现（阿里云、华为、七牛、腾讯、DebugDingTalk），通过 `SmsClientFactoryImpl` 按渠道编号分发；`SmsConfiguration` 暴露工厂 Bean，`SmsChannelProperties`/`SmsCodeProperties` 管理配置。
- `justauth/`：封装 `me.zhyd.oauth` JustAuth，`AuthRequestFactory` 根据 `JustAuthProperties` 中的 `AuthDefaultSource` 或自定义 `ExtendProperties` 反射创建对应 `AuthRequest`，并支持按来源配置代理。
- `operatelog/`：实现 `mzt-logapi` 的 `IParseFunction`（如 `AdminUserParseFunction`、`DeptParseFunction`、`PostParseFunction` 等），用于在操作日志中解析业务实体。
- `datapermission/`、`web/`、`weixin/`：分别提供数据权限、Web 层、微信客户端的 Spring `@Configuration` 装配类。
依赖方向单向向外：各子包仅依赖 `framework-common`、`module-system` 的 DO/Service 以及第三方 SDK，不反向依赖业务 service 层；`enums/` 与 `util/oauth2/OAuth2Utils` 作为纯常量与工具被 framework 各子包共享。

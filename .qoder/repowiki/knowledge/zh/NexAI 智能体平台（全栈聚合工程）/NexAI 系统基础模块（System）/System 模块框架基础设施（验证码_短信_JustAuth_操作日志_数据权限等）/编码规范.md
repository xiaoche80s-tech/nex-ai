- 每个功能域采用 `config/` + `core/` 分层：`config` 下放置 `@Configuration` 装配类与 `@ConfigurationProperties`，`core` 下放置核心接口与实现。
- 对外部第三方 SDK 通过本地接口抽象（如 `SmsClient`、`AuthRequestFactory`）屏蔽差异，新增厂商只需实现接口并由工厂分发。
- 错误码集中定义在 `ErrorCodeConstants` 接口中，按业务域分段使用 `1-002-xxx-xxx` 三段式编号，消息体使用占位符 `{}` 参数化。
- 字典类型、日志记录模板、OAuth2 常量等字符串常量统一收敛到 `DictTypeConstants`、`LogRecordConstants`、`oauth2/*` 等接口中，避免散落在业务代码。
- 可热更新的组件通过 `refresh(properties)` 模式（如 `AbstractSmsClient.refresh`）对比新旧配置后重新初始化，保证运行时配置变更生效。
- 操作日志解析器实现 `IParseFunction` 接口并以 `functionName()` 返回固定名称，便于日志模板通过 `${getAdminUserById(#id)}` 等形式引用。

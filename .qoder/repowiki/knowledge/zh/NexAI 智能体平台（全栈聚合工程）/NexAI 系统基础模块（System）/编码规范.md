- 每个领域子域均提供 `controller/admin` 管理后台接口与 `api` 远程 API（接口+Impl 分离），供其他模块调用。
- 数据层统一采用 `dataobject/*DO.java` + `mysql/*Mapper.java` 的 MyBatis 映射模式，并按领域分包。
- 跨模块 DTO 与 DO 之间通过 `convert/*Convert.java`（MapStruct）进行转换，避免在 Service 中手写映射。
- 错误码、日志记录键、字典类型常量集中在 `enums` 下的 `ErrorCodeConstants`、`LogRecordConstants`、`DictTypeConstants` 等文件中统一管理。
- 可插拔能力（验证码、短信、JustAuth、操作日志解析、数据权限）通过 `framework/*` 下的 Configuration 类以 Spring 自动装配方式启用。

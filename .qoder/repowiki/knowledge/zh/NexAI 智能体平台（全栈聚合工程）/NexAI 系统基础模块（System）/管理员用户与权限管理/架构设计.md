模块按三层划分：`api/user` 定义跨模块调用的 `AdminUserApi` 接口及 `AdminUserRespDTO`，由 `AdminUserApiImpl` 实现并借助 `DeptService` 组装下属部门用户；`controller/admin/user` 暴露 REST 端点，`UserController` 负责用户全生命周期（CRUD、分页、Excel 导入/导出、免鉴权简查），`UserProfileController` 处理当前登录用户的个人中心操作；`service/user` 通过 `AdminUserService` 接口封装业务逻辑，被 Controller 和 ApiImpl 共同依赖。数据访问层未在此范围内，但 Controller 通过 `UserConvert` 将 DO 转为 VO，并通过 `DeptService`、`PostService`、`RoleService`、`PermissionService` 横向协作完成部门、岗位、角色信息拼接。权限控制采用 Spring Security 的 `@PreAuthorize("@ss.hasPermission(...)")` 注解在 Controller 方法级声明，部分查询场景使用 `@DataPermission(enable = false)` 或 `DataPermissionUtils.executeIgnore` 关闭数据权限以避免误过滤。

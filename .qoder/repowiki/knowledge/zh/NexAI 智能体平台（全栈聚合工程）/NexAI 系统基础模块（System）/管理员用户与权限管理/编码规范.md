- Controller 方法统一返回 `CommonResult<T>` 包装，并使用 `@Valid`/`@Validated` 校验请求体参数。
- 需要权限控制的接口通过 `@PreAuthorize("@ss.hasPermission('system:user:*')")` 在方法上声明细粒度权限码。
- 对外暴露的远程 API 以 `*Api` 接口 + `*ApiImpl` 服务类形式实现，并在必要时通过 `DataPermissionUtils.executeIgnore` 或 `@DataPermission(enable = false)` 关闭数据权限。
- DO 到 VO/DTO 的转换统一通过 MapStruct 生成的 `UserConvert.INSTANCE` 完成，避免手写映射。
- 分页与列表查询中批量获取关联部门信息时，先收集所有 `deptId` 再调用 `deptService.getDeptMap` 一次性填充，减少 N+1 查询。
- VO 按用途拆分目录：`vo/user` 用于用户管理页面，`vo/profile` 用于个人中心，保持职责单一。

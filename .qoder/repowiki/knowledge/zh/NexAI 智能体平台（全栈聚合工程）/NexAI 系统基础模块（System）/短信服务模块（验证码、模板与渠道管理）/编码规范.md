- 对外 RPC 接口采用「接口 + `*Impl` 实现」分离模式，实现类标注 `@Service` 并通过 `@Resource` 注入对应 Service 进行转发。
- 管理后台 Controller 统一返回 `CommonResult<T>`，使用 `@PreAuthorize("@ss.hasPermission('...')")` 声明细粒度权限点，并使用 `BeanUtils.toBean` 在 VO 与 DO 之间转换。
- Service 方法对写操作使用 `@CacheEvict(cacheNames = RedisKeyConstants.SMS_TEMPLATE, allEntries = true)` 清空模板缓存，读操作使用 `@Cacheable` 按 code 缓存。
- DTO/VO 入参统一使用 `jakarta.validation.Valid` 触发参数校验，并在方法签名中显式标注。
- 异常通过 `ServiceExceptionUtil.exception(ErrorCodeConstants.XXX)` 抛出统一业务异常，错误码集中在 `ErrorCodeConstants` 中定义。
- 模板内容中的 `{xxx}` 变量通过正则 `\{(.*?)}` 解析并序列化为 JSON 字段存储，发送时再回填到模板参数。

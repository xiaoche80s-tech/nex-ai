- 每个功能域（登录日志、操作日志）均拆分为 api 接口+实现、controller、service 三层，并以同名 *Impl / *ServiceImpl 后缀区分实现类。
- Controller 方法统一使用 `@Validated` + `@Valid` 校验入参 VO，并通过 `@PreAuthorize("@ss.hasPermission('...')")` 声明细粒度权限。
- 对外暴露的 DTO 放在 `api/logger/dto`，管理后台 VO 放在 `controller/admin/logger/vo/<domain>`，二者与 DO 之间通过 `BeanUtils.toBean` 进行转换。
- 导出接口统一设置 `PageParam.PAGE_SIZE_NONE` 获取全量数据，再调用 `ExcelUtils.write` 输出 `.xls` 文件，并使用 `@ApiAccessLog(operateType = EXPORT)` 记录导出行为。
- 跨模块 API 实现类以 `@Service` + `@Validated` 标注，内部仅委托对应 Service，不直接依赖 DAL 或业务逻辑。

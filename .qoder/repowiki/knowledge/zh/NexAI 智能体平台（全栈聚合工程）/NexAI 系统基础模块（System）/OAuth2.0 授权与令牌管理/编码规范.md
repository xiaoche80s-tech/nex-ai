- Controller 统一返回 `CommonResult<T>`，并通过 `BeanUtils.toBean` 将 DO/VO 在边界处转换。
- 管理后台接口使用 `@PreAuthorize("@ss.hasPermission('...')")` 声明 RBAC 权限，开放接口使用 `@PermitAll` 配合 Basic Auth 与 `@ss.hasScope` 进行 scope 控制。
- Service 层采用接口+`ServiceImpl` 命名约定，并通过 `@Resource` 注入下游服务，grant 流程在 `OAuth2GrantServiceImpl` 中集中编排调用 Token/Code/Client 服务。
- 对外部应用的 OpenAPI 集中在 `OAuth2OpenController`，内部管理 API 拆分为独立的 Client/Token/User Controller，按 `/system/oauth2-*` 路径前缀区分。

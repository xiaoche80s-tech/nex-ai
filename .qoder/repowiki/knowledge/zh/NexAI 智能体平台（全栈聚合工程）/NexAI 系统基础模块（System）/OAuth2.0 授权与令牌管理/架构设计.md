模块按三层划分：`api/oauth2` 下的 `OAuth2TokenApiImpl` 实现框架层 `OAuth2TokenCommonApi`，作为跨模块 RPC 入口，仅做 DTO↔DO 转换并委派给服务；`controller/admin/oauth2` 暴露两类 HTTP 接口——`OAuth2OpenController`（`/system/oauth2/*`，对外部应用开放，通过 Basic Auth + scope 控制）提供 token、check-token、authorize 等标准端点，以及 `OAuth2ClientController`、`OAuth2TokenController`、`OAuth2UserController`（均带 `@PreAuthorize` 权限注解）供管理后台使用；`service/oauth2` 以接口+实现形式拆分职责：`OAuth2GrantService` 编排四种 grant 流程，`OAuth2CodeService` 负责授权码生命周期，`OAuth2TokenService` 封装 access/refresh token 的创建、校验、撤销与清理，`OAuth2ClientService` 负责客户端校验与缓存，`OAuth2ApproveService` 处理用户授权审批。依赖方向单向：Controller → Service → DO/其他服务，不直接访问持久层。

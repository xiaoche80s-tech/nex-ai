模块严格遵循 DDD 四层划分：
- interfaces：`interfaces/controller/admin/skill/SkillController` 暴露 `/ai/skill/*` REST 接口，使用 `@PreAuthorize` 权限控制并委托给应用层。
- application：以 `SkillService` 为入口，接收 `Command/Query/DTO`（如 `SkillCreateCommand`、`SkillPageQuery`），编排领域操作并调用 domain gateway 完成文件物化。
- domain：聚合根 `Skill` 维护不可变版本链（`SkillVersion` + `SkillContent`），通过 `SkillRepository` 端口与持久化解耦；对外暴露 `gateway/SkillMaterializationGateway` 用于将版本内容物化为 agentscope 可读取的文件目录。
- infrastructure：`SkillRepositoryImpl` 通过 MyBatis Mapper（`SkillMapper`/`SkillVersionMapper`/`SkillResourceMapper`）与 DO 对象（`SkillDO`/`SkillVersionDO`/`SkillResourceDO`）交互，并由 `SkillConverter` 负责领域模型与 DO 的双向转换；`AgentscopeSkillMaterializationGateway` 实现文件物化网关。
依赖方向单向：interfaces → application → domain ← infrastructure（domain 不感知框架）。测试覆盖 controller、repository 与 gateway 三个层次。

本模块是 NexAI 平台的 AI 能力层，按领域边界拆分为多个 DDD 聚合（agentspec/skill/session/channel/mcpserver/apikey/audit/usage），每个聚合内部统一采用 application/domain/infrastructure/interfaces 四层结构，通过接口暴露管理后台 REST API；各聚合之间不直接耦合，而是经由 shared/runtime（租户/会话上下文键）、shared/tool（工具库扩展点）以及 framework/config（OpenAPI、可观测性、通用配置）共享基础设施。运行时编排由 session 聚合驱动：它根据 agentspec 解析出的版本快照装配 channel 提供的 ChatModel 与 mcpserver 提供的工具，在调用链上经 audit 采集审计事件、经 usage 采集用量指标，并以 apikey 完成租户鉴权；AgentScope 调试会话数据持久化到 .agentscope/workspace 下按 agent 类型分目录的 sessions 与 default 目录中。

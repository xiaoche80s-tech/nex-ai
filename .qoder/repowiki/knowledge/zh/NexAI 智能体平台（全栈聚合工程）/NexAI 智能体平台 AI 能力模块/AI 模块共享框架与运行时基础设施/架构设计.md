本模块按职责划分为三个子包：
- `shared/tool`：定义平台工具库扩展点 `PlatformToolEntry`（id/code/name/description/toolNames/toolInstance），由 `PlatformToolRegistry` 通过 Spring 注入全部 `PlatformToolEntry` Bean 并构建按 id 索引的只读映射，启动期检测编号冲突；`builtin/SampleEchoTool` 作为实现示例，使用 agentscope 的 `@Tool`/`@ToolParam` 注解暴露具体工具方法。
- `shared/runtime`：集中声明 `RuntimeContextKeys` 常量（tenantId/sessionKey/agentId/specId/versionNo），供 session 装配、audit/usage 采集 middleware 三处共用同一字符串键，避免漂移。
- `shared/util`：纯静态工具类集合——`TenantExecution` 在异步线程恢复租户上下文，`RootCauses` 提取异常根因消息并截断，`Hashes` 提供 SHA-256 内容寻址。
- `framework/config`：Spring Boot 配置层，`AiObservabilityProperties` 与 `AiRuntimeProperties` 通过 `@ConfigurationProperties` 绑定 `nexai.ai.observability` 与 `nexai.ai.runtime` 前缀；`AiOtelConfiguration` 以 `@ConditionalOnProperty` 条件初始化全局 OpenTelemetry SDK，桥接 Spring Environment 中的 `otel.*` 属性；`AiOpenApiConfiguration` 放行 `/app-api/ai/openai/**` 路径并注册 `ApiKeyAuthFilter`，同时调整 WebMvc 转换器保证 SSE UTF-8 输出。
- `enums/ErrorCodeConstants`：集中声明 AI 模块错误码，按 channel(002)/model(003)/agentspec(004)/session(005)/skill(006)/mcpserver(007)/apikey(010) 等聚合段分配号段，依赖上层 `framework.common.exception.ErrorCode`。
依赖方向：本模块不依赖业务聚合，仅被各聚合反向引用；对外暴露的是接口（`PlatformToolEntry`）、常量（`RuntimeContextKeys`、`ErrorCodeConstants`）与 Spring 配置 Bean。

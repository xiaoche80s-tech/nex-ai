- 每个业务聚合遵循 application/domain/infrastructure/interfaces 四层分层，domain 仅含 model 与 repository 接口，infrastructure 实现数据访问与外部适配，interfaces.controller.admin.* 暴露管理后台 API。
- 跨聚合共享能力集中在 shared/ 与 framework/ 包：运行时上下文键放 shared/runtime，工具注册扩展点放 shared/tool，框架级配置集中放在 framework/config。
- 对外错误码统一收敛在 enums/ErrorCodeConstants 中定义，各聚合通过该常量集返回标准化错误。
- AgentScope 调试会话按 agent 类型（如 contract-agent-v1、skill-agent-v1）在 .agentscope/workspace/t1-user/{agent}/sessions 与 default 目录下以 jsonl 形式落盘。

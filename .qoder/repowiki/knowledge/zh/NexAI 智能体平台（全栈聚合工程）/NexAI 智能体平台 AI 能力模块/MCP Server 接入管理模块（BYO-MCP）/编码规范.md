- 领域聚合根使用静态工厂方法（`create`/`reconstitute`）构造实例，并通过私有构造函数 + `snapshotList`/`copyMap` 保证不可变快照，避免外部直接修改内部集合。
- 所有入参校验集中在 `validateBasics` 等方法中抛出 `IllegalArgumentException`，对长度、互斥字段（如 stdio 与 HTTP 传输字段）进行防御性检查。
- 对外部依赖通过 domain 层端口抽象（`McpServerGateway`、`McpServerRepository`）解耦，infrastructure 仅实现这些接口，领域层不引用 Spring/MyBatis/agentscope。
- Repository 实现使用 Converter + reconstitute 模式将 DO 还原为聚合根，枚举解析失败时直接抛 `IllegalStateException` 暴露脏数据而非静默吞错。
- 网关探测不抛异常，而是将成败、耗时、根因消息与工具清单统一封装为 `McpProbeResult` 返回，调用方据此决定后续流程。
- Controller 统一通过 `CommonResult.success(...)` 包装返回值，并使用 `@Validated` + `@Valid` 对请求体与 Query 对象做参数校验。

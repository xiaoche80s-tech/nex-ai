- 领域模型通过静态工厂方法构造（`TenantApiKey.issue` 用于新建、`reconstitute` 用于落库重建），并在工厂内执行名称长度、前缀非空、规格白名单去重等不变式校验。
- API Key 明文永不落库也不回传，仅存储 SHA-256 哈希与识别前缀；创建时一次性返回明文，吊销即单向置 `REVOKED` 实现泄漏止损。
- 应用层按 CQRS 风格拆分入参与出参：命令用 `command/*`、查询用 `query/*`、响应用 `dto/*`，服务接口只暴露聚合后的 DTO/PageResult。
- 管理端控制器统一使用 `CommonResult.success(...)` 包装返回值，并通过 `@PreAuthorize("@ss.hasPermission('ai:api-key:...')")` 声明细粒度权限点。
- 认证过滤器继承 `OncePerRequestFilter`，通过 `shouldNotFilter` 精确匹配 `/app-api/ai/openai/` 前缀，失败时直接写入 OpenAI 兼容 JSON 401 响应体。

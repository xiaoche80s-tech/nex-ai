采用六边形/分层架构（ADR-0001）：
- domain 层定义 Session 聚合根（Session/SessionStatus/SessionType）、值对象（AgentRuntimeConfig、ChatMessageInput、RuntimeEvent、ToolCallDecision、SkillMountDirectory）以及出端口 AgentRuntimeGateway，不依赖任何框架。
- application 层通过 SessionService / OpenAiCompatService 编排跨聚合只读操作（规格版本快照、渠道、模型），将命令（DebugSessionCreate/Message/ConfirmCommand）、查询（SessionPageQuery）和 DTO（SessionDTO、PendingConfirmationDTO）映射到领域；事件以 Flux<RuntimeEvent> 形式返回，控制器零 agentscope 依赖。
- infrastructure 层提供 AgentRuntimeGateway 的实现 AgentscopeRuntimeGateway + RuntimeToolContributor，封装对 agentscope HarnessAgent 的调用；AgentInstanceManager 按 specReference + 版本戳缓存常驻实例并做引用计数与失效重建；SessionRepositoryImpl + SessionMapper + SessionDO 完成持久化；AssembledAgent / EventTranslator 负责装配与事件翻译。
- interfaces 层暴露两类入口：admin/session 下的 DebugSessionController（/ai/session，SSE 经 SseBridge 桥接 Flux→SseEmitter）与 app/openai 下的 OpenAiCompatController（/app-api/ai/openai/chat/completions，OpenAI 流式协议适配）。
依赖方向严格自上而下：interfaces → application → domain ← infrastructure（通过 domain.gateway 端口反向注入）。

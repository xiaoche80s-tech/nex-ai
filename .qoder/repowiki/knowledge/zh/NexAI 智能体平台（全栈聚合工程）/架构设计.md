根工程采用 Maven 多模块组织：`server` 作为 Spring Boot 可执行入口，依赖 `module_system`、`module_infra`、`module_ai` 等后端子模块；`nexai_framework` 提供统一的 AutoConfiguration.imports 自动装配机制，使各 Starter 在启动时按需加载横切能力；`ui` 为独立的前端工程，通过 API 与 `server` 通信；`sql_scripts` 提供 MySQL/PostgreSQL/达梦三套 DDL 及 Flowable 适配补丁，由部署脚本驱动初始化；`scripts` 与 `Dockerfile` 共同完成构建、打包与容器化发布；`docs` 集中保存架构决策与领域说明。各模块之间通过明确的 API 包与远程接口解耦，`server` 是唯一编排运行时边界的聚合点。

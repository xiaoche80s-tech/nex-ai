- 每个业务子域在 views/infra 和 api/infra 下保持同名目录，API 文件统一命名为 index.ts 并集中导出 VO/ReqVO 类型与请求函数。
- 列表页采用统一模板：顶部搜索表单（queryParams 含 pageNo/pageSize）、中间 el-table + Pagination、底部通过 ref 引用的弹窗 Form/Detail 组件。
- 删除/批量删除/状态变更等危险操作统一通过 message.delConfirm() 或 message.confirm() 二次确认后调用 API，再刷新列表。
- 按钮级权限通过 v-hasPermi 指令绑定 infra:*:action 形式的权限字符串，新增/编辑/删除/导出等操作均受其控制。
- API 层函数命名遵循 get/create/update/delete/export 前缀 + 资源名（如 getCodegenTablePage、createConfig、deleteFileList），参数以 PageParam 对象传递分页。
- 视图组件通过 defineOptions({ name: 'InfraXxx' }) 显式声明组件名，并使用 useMessage/useI18n/useRouter 等全局 composable 进行交互。

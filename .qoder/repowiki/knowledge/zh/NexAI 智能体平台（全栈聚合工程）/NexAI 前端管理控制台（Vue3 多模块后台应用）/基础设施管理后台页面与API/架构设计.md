模块按业务子域划分为 views/infra 下的独立目录（如 codegen、job、config、file、dataSourceConfig、apiAccessLog、apiErrorLog、redis、druid、swagger、webSocket、server、skywalking、build、demo），每个子域通常包含 index.vue（列表/主入口）以及可选的 Form/Detail/组件；对应的 API 层位于 src/api/infra/<子域>/index.ts，通过统一的 request 实例（@/config/axios）发起 HTTP 请求，并在同一文件中导出 TS 类型定义（VO/ReqVO）。依赖方向严格为 views → api → axios，视图之间不直接互相调用，跨域数据通过共享的 DataSourceConfigApi 等 API 间接获取。codegen 子域结构最复杂，拆分为 components（BasicInfoForm/ColumInfoForm/GenerateInfoForm）、ImportTable、PreviewCode、EditTable 等子组件，由 index.vue 组合编排；job 子域进一步拆出 logger 子目录用于执行日志查看。所有页面统一使用 Element Plus 表格+分页、useMessage/useI18n/useRouter 等组合式 API，并通过 v-hasPermi 指令控制按钮级权限。

模块按业务域划分为 views/bpm 与 api/bpm 两层：
- API 层（src/api/bpm/*）：每个子目录对应一个后端资源（category、definition、form、model、processInstance、task、comment、processExpression、processListener、userGroup、leave、simple），统一通过 `@/config/axios` 发起 HTTP 请求，并导出 TypeScript 类型（如 ModelVO、ProcessInstanceVO）供视图层引用。
- 视图层（src/views/bpm/*）：以路由页面为入口，采用「列表页 + 表单页 + 详情页」三段式组织。核心子域包括：
  - model/form：四步向导（基本信息→表单设计→流程设计→更多设置），通过 provide/inject 共享 formData/processData，各步骤组件暴露 validate() 方法由父级集中校验后调用 ModelApi.create/update/deploy。
  - processInstance：my-page/manager-page 列表 → detail 详情（含 form/diagram/record/comment 多标签）、create 发起、report 报表；详情内拆分为 ProcessInstanceBpmnViewer、ProcessInstanceSimpleViewer、ProcessInstanceTaskList、ProcessInstanceCommentList、ProcessInstanceOperationButton、ProcessInstanceTimeline、SignDialog、PrintDialog 等细粒度子组件。
  - task/todo、task/done、task/manager、task/copy：任务代办/已办/管理/转交列表，均复用统一的搜索栏+表格+分页结构，跳转至 BpmProcessInstanceDetail。
  - category、group、processExpression、processListener：基础配置 CRUD。
  - oa/leave：内置请假单示例（create/detail/index）。
- 依赖方向单向：views → api → @/config/axios；跨模块数据（分类、用户、部门）通过 system 相关 API 获取；常量（BpmModelType、BpmModelFormType、DICT_TYPE）集中在 @/utils/constants 与 @/utils/dict。

- API 文件按后端资源一一对应目录（如 processInstance/index.ts），统一通过 `import request from '@/config/axios'` 封装 GET/POST/PUT/DELETE，并导出 TS 类型定义。
- 列表页面统一采用「搜索表单 + ContentWrap + el-table + Pagination」布局，查询参数集中在 reactive queryParams 中，通过 handleQuery/resetQuery/getList 三件套驱动。
- 字典值通过 `DICT_TYPE.*` 配合 `dict-tag`、`getIntDictOptions` 渲染，状态码集中来自 `@/utils/constants`（如 BpmProcessInstanceStatus、BpmModelType）。
- 复杂页面使用 defineOptions({ name: '...' }) 声明组件名，便于 tagsView 与调试识别。
- 多步骤表单通过 ref 数组 + validator 函数数组驱动，保存时依次 await 各步骤 validate() 再统一提交。
- 权限控制使用 v-hasPermi 指令（如 `['bpm:process-instance:cancel']`）包裹操作按钮，与后端 RBAC 对齐。

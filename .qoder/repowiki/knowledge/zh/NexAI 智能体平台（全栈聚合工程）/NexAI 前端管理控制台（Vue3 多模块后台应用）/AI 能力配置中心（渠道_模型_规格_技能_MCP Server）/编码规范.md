- 每个业务子域在 `views/ai/<domain>/` 与 `api/ai/<domain>/` 下成对存在 index.vue 与 index.ts，职责边界清晰且一一对应。
- API 文件统一先定义 VO/Form/PageParams 等 TS 类型，再导出同名方法（如 createChannel/updateChannel/getChannelPage），并通过 `request.get/post/put/delete` 调用 `/ai/<resource>/...` 风格的后端 URL。
- 列表页遵循「搜索表单 + el-table + Pagination + 弹窗表单」四段式结构，查询参数使用 `reactive({ pageNo, pageSize, ... })` 并以 `handleQuery/resetQuery` 重置到第一页后重新拉取。
- 状态开关（enabled/published）采用乐观更新：先修改本地字段，调用成功后提示成功，catch 中回滚字段值以保证 UI 与后端一致。
- 按钮级权限统一通过 `v-hasPermi="['ai:<resource>:create|update|delete|query']"` 指令声明，与后端资源命名保持一致。
- 所有用户可见文案通过 `useI18n().t('ai.<domain>.xxx')` 获取，键名按 domain 分组，禁止硬编码中文/英文字符串。
- 表单组件通过 `ref` + `open(id?)` 暴露式复用，父组件监听 `@success` 事件触发列表刷新。

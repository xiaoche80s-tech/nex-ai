模块按「视图层 views/ai + 接口层 api/ai」双目录组织，每个业务子域（channel、spec、skill、mcpserver、apikey、platformTool、session）在两层各自拥有独立子目录与 index.ts/index.vue 入口。
- 视图层：基于 Vue 3 `<script setup>` + Element Plus，使用 `ContentWrap`、`el-table`、`Pagination`、`el-dialog`/`el-drawer` 等通用组件；列表页统一采用「搜索表单 + 表格 + 分页 + 弹窗表单」布局，复杂页面（如 channel 同时管理渠道与模型、skill 用卡片网格+抽屉详情）通过组合多个子组件完成。
- 接口层：所有 HTTP 调用集中封装在 `@/api/ai/<domain>/index.ts`，通过 `request`（`@/config/axios`）发起 get/post/put/delete/upload，并导出 TS 类型（VO/Form/PageParams）供视图层引用，形成单向依赖 views → api → axios。
- 权限控制：按钮级权限通过 `v-hasPermi="['ai:*:create|update|delete|query']"` 指令声明，与后端资源命名一致。
- 国际化：所有文案通过 `useI18n().t('ai.*')` 读取，键名以 `ai.<domain>.` 前缀分组。
- 数据流：列表查询统一走 `getXxxPage(params)` 返回 `{list, total}`；状态切换（enabled/published）采用乐观更新 + catch 回滚模式；表单通过 ref + `open(id?)` 暴露式复用。
- 版本化设计：spec 与 skill 均支持「草稿→版本快照→当前版本指针」三态管理，列表根据 `hasDraft/currentVersionNo` 渲染不同标签，版本操作集中在 SpecVersion / 技能抽屉内。

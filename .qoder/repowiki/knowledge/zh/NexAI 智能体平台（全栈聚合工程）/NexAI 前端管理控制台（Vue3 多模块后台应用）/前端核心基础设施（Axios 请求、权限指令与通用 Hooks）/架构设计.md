模块按职责划分为三个并列子目录：
- `config/axios`：以 `service.ts` 创建单个 Axios 实例并注册 request/response 拦截器，实现统一注入 Authorization、租户头（tenant-id/visit-tenant-id）、GET 防缓存、form-urlencoded 序列化、API 加解密；response 层处理 401 无感知刷新令牌（基于 `requestList` 队列与 `isRefreshToken` 标志）、错误码映射到 i18n 消息、blob/arraybuffer 下载分支；`index.ts` 对外暴露 get/post/delete/put/download/upload 及带 Original 后缀的原始响应方法；`config.ts` 集中 base_url/result_code/timeout/default_headers 配置。
- `directives`：通过 `setupAuth` 在应用启动时挂载 `v-hasRole`（读取 wsCache 中 USER 角色，支持 super_admin 通配）和 `v-hasPermi`（读取 Pinia userStore.permissions，支持 `*:*:*` 通配），未命中时直接移除 DOM 节点；另提供 `setupMountedFocus` 聚焦指令。
- `hooks/web`：每个文件一个独立组合式函数，围绕 Element Plus、i18n、Pinia store、web-storage-cache 等能力封装复用逻辑（如 useMessage、useI18n、useCache、useDesign、useTable、useForm、useTagsView、useWatermark 等），被业务组件按需引入；`hooks/event` 存放事件类 hook（如 useScrollTo）。
依赖方向：hooks/directives 可依赖 axios service 与 store/utils，但 axios 不反向依赖 hooks（仅通过 import.meta.env 与 utils/auth 解耦）。

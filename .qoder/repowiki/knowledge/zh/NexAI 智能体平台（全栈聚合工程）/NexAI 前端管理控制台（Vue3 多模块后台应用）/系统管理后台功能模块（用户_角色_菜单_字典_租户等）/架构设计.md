模块按业务领域划分为 views/system/<domain>/ 与 api/system/<domain>/ 两套平行目录，每个子域（如 user、role、dept、dict、mail、sms、notify、oauth2、social、tenant、notice、post、menu、area、loginlog、operatelog、permission 等）独立成文件夹，内部遵循统一的三层结构：index.vue 作为列表页（搜索+表格+分页），Form.vue 负责新增/编辑弹窗，Detail.vue 或 components/* 处理详情与复用组件；api 层每个 domain 对应一个 index.ts，通过统一封装的 request（@/config/axios）暴露 CRUD 方法，视图层仅依赖 API 层而不直接调用 HTTP。权限控制通过 v-hasPermi 指令与 checkPermi 函数在按钮级裁剪操作入口，数据展示使用全局字典 DICT_TYPE 配合 dict-tag/int 渲染枚举值，导出统一走 download.excel 工具并配合 message.exportConfirm 二次确认。跨域共享组件（DeptTreeSelect、UserSelect、RoleSelect、TemplateSelect 系列）放在各自 components 目录下供同域及相邻域复用。

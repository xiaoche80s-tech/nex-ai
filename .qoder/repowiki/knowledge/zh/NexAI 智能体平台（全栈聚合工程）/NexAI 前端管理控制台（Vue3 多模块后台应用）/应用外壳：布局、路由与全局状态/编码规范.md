- 布局子组件采用 `<Name>/src/*.vue` + `<Name>/index.ts` 的自包含目录结构，由 index 统一再导出。
- CSS class 前缀统一通过 `useDesign().getPrefixCls('xxx')` 生成，避免硬编码命名空间。
- Pinia store 以 `defineStore('id', { state, getters, actions })` 形式定义，并在文件末尾暴露同名 `useXxxStoreWithOut(store)` 供 setup 外调用。
- 需要跨会话保存的配置项通过 `useCache().wsCache` 读写，并以 `CACHE_KEY.*` 常量作为键。
- 路由元信息统一使用 `meta` 字段表达可见性、缓存、面包屑、标签页等行为（hidden/noCache/affix/breadcrumb/noTagsView/canTo/activeMenu）。
- 布局渲染通过 switch 分发不同 render 函数，新增布局只需在 `useRenderLayout` 中增加分支并在 `Layout.vue` 中注册对应模式。

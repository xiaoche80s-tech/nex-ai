模块由三个并列子目录构成应用壳层：
- `layout/`：以 `Layout.vue` 为根入口，通过 `useRenderLayout.tsx` 暴露 `renderClassic/renderTopLeft/renderTop/renderCutMenu` 四种布局渲染函数，由 `getLayoutRenderMode` 根据 `appStore.getLayout` 动态选择；各子组件（Menu、TagsView、TabMenu、Logo、ToolHeader、Setting、Breadcrumb、LocaleDropdown、SizeDropdown、Screenfull、ThemeSwitch、UserInfo、Message、Footer、ContextMenu、Collapse、AppView）按职责拆分到 `components/<Name>/src/*.vue` + `index.ts` 的自包含结构，并通过 `useDesign().getPrefixCls` 生成命名空间 CSS class。
- `router/`：`index.ts` 使用 `vue-router` 创建实例并挂载，`scrollBehavior` 统一滚动复位，`onError` 处理动态 chunk 加载失败后刷新页面；`modules/remaining.ts` 集中声明无需权限控制的静态路由（登录、404、redirect、Home、bpm 等），所有业务路由由外部权限模块在运行时注入。
- `store/`：`index.ts` 用 `createPinia()` 创建 store 并启用 `pinia-plugin-persistedstate` 持久化；`modules/` 下按领域划分 state（`app`、`user`、`permission`、`tagsView`、`locale`、`dict`、`lock`、`bpm/*`、`mall/*`），每个 store 通过 `defineStore` 定义 state/getters/actions，并提供 `useXxxStoreWithOut` 以便在 setup 之外访问 store。
依赖方向：layout 消费 store（app/permission/tagsView）和 router（via `<router-view>` 的 AppView），router 与 store 之间无直接耦合，三者共同构成应用的启动骨架。

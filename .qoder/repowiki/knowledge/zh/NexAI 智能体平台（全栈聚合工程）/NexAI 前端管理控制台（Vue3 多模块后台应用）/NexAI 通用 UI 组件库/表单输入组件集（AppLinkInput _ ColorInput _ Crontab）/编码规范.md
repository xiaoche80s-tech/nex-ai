- 组件统一通过 `defineOptions({ name: '...' })` 声明组件名，便于调试与递归引用识别。
- 所有输入型组件以 `modelValue` prop + `update:modelValue` emit 实现 v-model 双向绑定，并在内部用本地 state 或 computed 进行中转。
- 复杂交互组件（AppLinkInput、Crontab）通过 `ref` + `defineExpose` 暴露命令式方法（如 `open`），由父组件主动触发弹窗而非受控显示。
- 数据与视图分离：静态配置（App 链接分组、Cron 可选值）集中在独立常量或 `data` 对象中，模板仅负责渲染。
- 对 Element Plus 组件实例使用具类型 ref（如 `ScrollbarInstance`、`ButtonInstance`）配合 `$refs` 访问原生滚动控制能力。

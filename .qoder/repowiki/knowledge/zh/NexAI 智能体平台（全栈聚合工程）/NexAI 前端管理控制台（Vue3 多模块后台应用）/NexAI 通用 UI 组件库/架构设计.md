组件以目录为单位组织，每个子组件遵循 src/xxx.vue + index.ts（或 index.vue）的约定：index.ts 负责导出 props/types，src 下放置主实现；根 components/index.ts 仅注册 Icon 为全局组件，其余组件由上层按需 import。子模块之间保持松耦合：FormCreate 与 DiyEditor 共享 schema/rule 思路但各自维护 config 目录；bpmnProcessDesigner 与 SimpleProcessDesignerV2 分别封装不同流程引擎的可视化能力；Table、Descriptions、Echart 等数据展示组件均基于 Element Plus 扩展，不直接互相依赖。跨子模块的复用通过共享的 Form 组件（如 DeptSelectForm、UserSelectForm、AppLinkInput）以及 UploadFile 提供的 useUpload hook 完成，避免在编辑器内部重复实现基础交互。

模块以 `useFormCreateDesigner` 作为唯一对外 hook（由 `index.ts` 统一导出），在 `onMounted` 中调用 `buildFormComponents` 和 `buildSystemMenu` 将各类规则注册到传入的 designer 实例：先移除内置的 upload/fcEditor/select 等菜单项，再追加自定义规则与对应拖拽按钮。

- `src/config/` 按职责拆分规则工厂：`useUploadFileRule/useUploadImgRule/useUploadImgsRule` 处理三类上传；`useDictSelectRule` 动态加载字典类型；`useAreaSelectRule`、`useIframeRule`、`useEditorRule` 分别提供地区选择、iframe、富文本；`useSelectRule` 是通用选择器规则工厂，被 UserSelect、DeptSelect、ApiSelect 复用，并通过 `selectRule.ts` 集中维护下拉/单选/多选控件的 props 配置与联动控制。
- `src/components/` 存放运行时 Vue 组件：`useApiSelect.tsx` 通过 `defineComponent` 动态生成 ApiSelect/UserSelect/DeptSelect 等选择器，封装 GET/POST 远程请求、parseFunc 解析、模板表达式 `${field}` 替换、默认当前用户等逻辑；其余 `.vue` 文件（AreaSelect、DeptSelect、DictSelect、IframeComponent）为具体渲染实现。
- `src/type/index.ts` 定义 Menu/MenuItem/ApiSelectProps/SelectRuleOption 等共享类型；`src/utils/index.ts` 提供 `makeRequiredRule`、`localeProps`（基于 i18n key 前缀翻译 props 标题）、`parseFormFields` 等工具。
- 依赖方向：hook → config 规则工厂 → utils/type → 运行时组件；模块仅依赖上层 FormCreate designer API（`addComponent`、`appendMenuItem`、`addMenu`、`removeMenuItem`、`getRule`、`setRule`），不反向依赖业务页面。

三个子模块各自封装一种可视化编辑场景：DiyEditor 提供移动端组件库与容器，按 `index.vue` + `config.ts` + `property.vue` 的三件套模式注册可拖拽组件；FormCreate 通过 `src/config/*Rule.ts` 向 FormCreate 注入自定义字段规则及运行时组件；bpmnProcessDesigner 基于 bpmn-js 插件化扩展（palette、content-pad、descriptor、extension-moddle、translate）实现流程建模。三者均作为独立 npm 包/目录被上层页面按需引入，彼此之间无直接依赖，仅共享同一 UI 框架（Vue3 + Element Plus）与主题样式体系。

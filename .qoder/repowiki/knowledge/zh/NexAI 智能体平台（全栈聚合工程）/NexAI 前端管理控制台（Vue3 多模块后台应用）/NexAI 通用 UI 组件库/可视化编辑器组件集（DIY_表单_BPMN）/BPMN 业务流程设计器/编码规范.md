- bpmn-js 插件统一以对象形式导出，包含 `__init__` 数组与键值对形式的服务注册（如 `paletteProvider: ['type', CustomPalette]`）。
- 属性面板的子配置项按业务域拆分子目录（task、listeners、multi-instance、time-event-config 等），由 `PropertiesPanel.vue` 依据 `elementType` 条件渲染。
- 引擎差异通过 `prefix` 属性分发：`ProcessDesigner.vue` 与 `PropertiesPanel.vue` 均根据 prefix 选择对应的 descriptor JSON 与 extension-moddle。
- Vue 组件采用 `defineOptions({ name })` 命名后通过 `.install(Vue)` 方法注册为全局组件，便于按需或全局引入。
- 模型变更通过监听 `commandStack.changed` 事件统一导出 xml，并以 `input/change/save/commandStack-changed` 等事件向父组件同步状态。

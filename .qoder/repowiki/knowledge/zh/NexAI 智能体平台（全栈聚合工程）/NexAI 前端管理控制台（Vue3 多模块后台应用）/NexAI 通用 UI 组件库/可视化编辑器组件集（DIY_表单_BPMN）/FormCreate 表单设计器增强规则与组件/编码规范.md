- 每个自定义组件通过一个 `useXxxRule` 工厂函数返回包含 `icon`、`label`、`name`、`rule()`、`props(_, { t })` 的对象，再由 designer 的 `addComponent` 注册。
- `rule()` 中统一使用 `generateUUID()` 生成 `field`，确保每次生成的规则拥有唯一标识。
- `props()` 中统一通过 `localeProps(t, name + '.props', [...])` 对规则标题进行 i18n 翻译，并以 `makeRequiredRule()` 开头插入必填校验规则。
- 选择类组件共用 `useSelectRule` 工厂，并将下拉/单选/多选的通用 props 集中在 `selectRule.ts` 中声明，通过 `cloneDeep` 复制避免污染。
- 新增组件时先在 `buildFormComponents`/`buildSystemMenu` 中调用 `designer.value?.removeMenuItem` 移除同名内置项，再追加自定义实现，保证覆盖行为一致。
- 通过 `watch(getRule(), fixDuplicateFields, { deep: true })` 监听设计器规则变化，发现重复 field 时用 `generateUUID()` 替换并 `setRule` 回写，防止复制组件导致 ID 冲突。

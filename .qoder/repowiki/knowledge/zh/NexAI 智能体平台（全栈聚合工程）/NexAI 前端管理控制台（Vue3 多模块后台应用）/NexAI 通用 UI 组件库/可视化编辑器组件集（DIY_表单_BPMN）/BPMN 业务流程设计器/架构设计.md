模块以 `package/designer/ProcessDesigner.vue` 为入口组件，在 `onMounted` 中实例化 `bpmn-js/lib/Modeler`，并通过 `additionalModules` 与 `moddleExtensions` 注入翻译、token 模拟、自定义 palette、rules、custom-renderer 等插件；同时根据 `prefix`（camunda/activiti/flowable）动态装配对应的 descriptor JSON 与 extension-moddle。

- `package/designer/plugins/`：按功能分目录组织 bpmn-js 插件——`palette`（左侧工具栏）、`content-pad`（右键内容菜单）、`translate`（i18n 翻译函数 + zh 字典）、`descriptor`（各引擎的 XML schema 描述）、`extension-moddle/{activiti,camunda,flowable}`（对应引擎的扩展字段解析），以及 `defaultEmpty.js` 生成空流程图 XML。
- `src/modules/`：纯 JS 的 bpmn-js 扩展模块，遵循 `{ __init__: [...], xxx: ['type', Ctor] }` 注册格式，包括 `custom-renderer`（自定义节点渲染）和 `rules`（连线/删除规则）。
- `package/penal/`：右侧属性面板，由 `PropertiesPanel.vue` 通过 `el-collapse` 聚合多个子配置项（基础信息、流转条件、表单、任务配置、监听器、多实例、信号消息、时间事件、扩展属性等），通过 `provide('prefix')` 向下传递引擎前缀，子组件据此渲染差异化表单。
- `package/palette/ProcessPalette.vue`：独立的可嵌入式左侧面板组件。
- 顶层 `package/index.ts` 统一导出 `MyProcessDesigner`、`MyProcessPenal`、`MyProcessViewer`，并全局引入 bpmn-js 样式与主题 SCSS。
依赖方向：上层 Vue 组件 → bpmn-js Modeler → 插件/扩展模块；属性面板通过 `window.bpmnInstances` 反向读取 modeler 内部服务（modeling/moddle/eventBus 等）。

- 每个组件目录固定包含 `config.ts`、`index.vue`、`property.vue` 三个文件，其中 `config.ts` 必须导出 `component: DiyComponent<T>` 并声明默认 `property`。
- 组件属性类型通过独立的 `interface XxxProperty` 在 `config.ts` 中定义，并在 `property.vue` 中以 `defineProps<{ modelValue: XxxProperty }>()` 接收，使用 `useVModel` 实现 v-model 双向绑定。
- 组件样式统一复用 `util.ts` 中的 `ComponentStyle` 接口（含 bgType/bgColor/bgImg/margin/padding/borderRadius 等），并在 `property.vue` 中通过 `ComponentContainerProperty` 包裹样式设置区块。
- 组件通过 `defineOptions({ name: 'Xxx' })` 显式声明名称，且 `config.ts` 中的 `id` 与目录名保持一致，以便 `index.ts` 自动推导 `${id}Property` 属性面板路径。
- 复杂列表型属性（如轮播项、菜单项）在 `property.vue` 中使用 `Draggable` 配合 `emptyItem` 实现可拖拽增删，并搭配 `UploadImg` / `UploadFile` / `AppLinkInput` 等通用输入组件。

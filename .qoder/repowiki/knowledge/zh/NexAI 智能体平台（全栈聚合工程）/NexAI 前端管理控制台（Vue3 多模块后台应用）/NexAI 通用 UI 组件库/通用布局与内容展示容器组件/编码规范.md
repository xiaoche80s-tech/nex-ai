- 每个子组件采用 `src/<Name>.vue` + 同级 `index.ts` 重导出的双文件组织方式，对外仅暴露单一组件名。
- 组件通过 `defineOptions({ name: '...' })` 显式声明组件名称，便于调试与错误追踪。
- 样式类名通过 `useDesign().getPrefixCls('xxx')` 生成带命名空间的 BEM 风格前缀，避免全局样式冲突。
- Props 统一使用 `@/utils/propTypes` 中的 `propTypes.string.def(...)` / `propTypes.object.def(...)` 进行类型声明与默认值设置。
- 插槽设计遵循“默认插槽承载主体内容 + 具名插槽承载扩展区域”的模式（如 `header`、`right`、`title`）。

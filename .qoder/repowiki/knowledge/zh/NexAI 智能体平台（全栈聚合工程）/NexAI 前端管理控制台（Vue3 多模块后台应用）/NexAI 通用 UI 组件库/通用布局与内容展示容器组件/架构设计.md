模块由三个并列的 Vue 3 单文件组件构成，每个组件遵循统一的目录结构：`src/<Component>.vue` 实现逻辑与模板，根级 `index.ts` 仅做重导出，作为对外暴露的唯一入口。
- `Card/CardTitle.vue`：最小化展示型组件，通过 `defineProps` 接收 `title`，使用 scoped SCSS 以伪元素绘制左侧主题色装饰条。
- `ContentWrap/src/ContentWrap.vue`：基于 Element Plus `ElCard` 的内容容器，支持 `title`、`message`（配合 `ElTooltip` 提示）和 `bodyStyle` 属性，并提供 `header` 插槽扩展右侧操作区。
- `ContentDetailWrap/src/ContentDetailWrap.vue`：面向详情页的复合容器，组合 `Sticky` 粘性头部与 `ElCard` 主体；头部包含返回按钮（emit `back` 事件）、默认标题插槽与右侧插槽；通过 `useDesign().getPrefixCls` 生成 BEM 风格类名前缀，并使用 `getBoundingClientRect()` 在 `onMounted` 中计算滚动偏移量传递给 `Sticky`。
依赖方向单向向下：组件仅依赖项目内工具（`@/utils/propTypes`、`@/hooks/web/useDesign`、`@/i18n`）与 Element Plus 基础组件，不反向引用业务页面。

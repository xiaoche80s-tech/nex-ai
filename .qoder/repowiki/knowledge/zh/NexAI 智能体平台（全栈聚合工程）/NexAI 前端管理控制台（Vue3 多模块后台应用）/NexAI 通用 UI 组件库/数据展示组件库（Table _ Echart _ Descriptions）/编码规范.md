- 每个子组件采用 `src/<Component>.vue` + 同级 `index.ts` 统一导出的目录约定，便于按需引入。
- 组件属性声明统一使用 `@/utils/propTypes` 的 `.def()` 链式语法定义默认值与校验规则。
- 样式命名空间通过 `useDesign().getPrefixCls()` 生成带 `namespace-` 前缀的 class，避免全局样式冲突。
- 对外暴露的命令式方法通过 `expose` 显式声明（如 Table 的 `setProps`/`setColumn`/`selections`），而非直接透传 ref。
- 动态列/字段渲染优先通过具名插槽（如 `${field}`、`${field}-header`、`${field}-label`）实现内容定制，fallback 到 formatter 或字段直取。

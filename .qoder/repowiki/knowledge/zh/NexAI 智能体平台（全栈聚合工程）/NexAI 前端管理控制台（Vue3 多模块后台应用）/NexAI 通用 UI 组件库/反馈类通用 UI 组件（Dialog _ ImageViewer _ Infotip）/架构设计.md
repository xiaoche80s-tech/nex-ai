模块由三个并列的子组件目录组成，每个子组件遵循相同的 `src/<Component>.vue` + `index.ts` 双文件结构：`index.ts` 仅做重导出或暴露函数式 API，业务逻辑集中在 Vue SFC 中。
- Dialog：基于 `ElDialog` 二次封装，通过 `getBindValue` computed 合并 `useAttrs()` 与 props 并过滤掉内部使用的 fullscreen/title/maxHeight/appendToBody/loading 等键，再 `v-bind` 透传；内置全屏切换、滚动容器（`ElScrollbar`）、loading 态与关闭动画（`closing` ref），样式通过覆盖 `#{$elNamespace}-dialog` 命名空间实现主题适配。
- ImageViewer：组件本身是 `ElImageViewer` 的薄包装，对外暴露 `createImageViewer(options)` 函数式 API，在 `index.ts` 中通过 `createVNode` + `render` 动态创建实例并挂载到 `document.body` 新增的容器中，调用方无需手动管理 DOM 生命周期；类型定义抽离至 `types.ts` 供外部消费。
- Infotip：纯展示型组件，使用 `useDesign().getPrefixCls('infotip')` 生成 BEM 风格 class，渲染 `schema` 数组（支持字符串或含 `keys` 的 `TipSchema` 对象），并通过 `Highlight` 子组件实现关键词高亮与点击回调。
依赖方向单向向下：所有组件均依赖项目内 `@/utils/propTypes`、`@/hooks/web/useDesign`、`@/types/infoTip` 等共享工具，不反向引用业务模块。

- 每个子组件采用 `src/<Name>.vue` 存放实现、同级 `index.ts` 仅做 re-export 或暴露函数式 API 的统一目录约定。
- Props 统一通过 `@/utils/propTypes` 的 `.def(...)` 链式语法声明默认值，避免手写 `default: () => ...`。
- 组件通过 `defineOptions({ name: '...' })` 显式声明组件名，便于调试与 DevTools 识别。
- 需要透传大量属性时，使用 computed 合并 `useAttrs()` 与 props 并删除内部保留字段后再 `v-bind`，而非逐一绑定。
- 样式通过覆盖 Element Plus 的 `#{$elNamespace}` 命名空间选择器（如 `#{$elNamespace}-dialog`）实现主题化定制。
- 函数式组件（如 ImageViewer）通过 `createVNode` + `render` 动态挂载到 `document.body` 新增的容器，并在调用前用 `isClient` 判断运行环境。

- 每个组件采用 `src/<Component>.vue` + 同级 `index.ts` 单一导出的目录约定，`index.ts` 仅做 `import ... from './src/...'` 再 `export { Component }`。
- 组件内部统一通过 `useDesign()` 获取 `getPrefixCls` 与 `variables`，并以 `${prefixCls}-xxx` 形式组织 BEM 风格类名。
- Props 定义集中使用 `propTypes`（来自 `@/utils/propTypes`）配合 `.def(...)` 设置默认值，并对数值类 prop 附加 `.validate(...)` 校验。
- 组件通过 `defineOptions({ name: '...' })` 显式声明组件名称，便于调试与递归引用。
- 需要跨层级共享状态时优先使用 `provide/inject`（如 ConfigGlobal 以字符串 key 注入 configGlobal），而非全局事件总线。

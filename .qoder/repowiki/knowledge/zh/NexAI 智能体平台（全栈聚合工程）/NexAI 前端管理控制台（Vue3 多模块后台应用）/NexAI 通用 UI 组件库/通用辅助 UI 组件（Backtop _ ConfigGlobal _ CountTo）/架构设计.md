模块由三个并列的独立子目录组成，每个子目录遵循统一的「src + index.ts」结构：`index.ts` 仅做单文件重导出，`src/*.vue` 为具体实现，对外暴露一个具名组件。
- Backtop：对 Element Plus 的 `ElBacktop` 进行薄封装，通过 `useDesign` 生成前缀类名并绑定到项目布局容器的滚动区域，屏蔽第三方库差异。
- ConfigGlobal：基于 `ElConfigProvider` 提供全局主题、尺寸、国际化等配置，使用 `provide('configGlobal', props)` 向后代注入配置；监听窗口尺寸变化并通过 `appStore` 切换移动端模式与布局，同时用 `setCssVar` 动态调整 CSS 变量。
- CountTo：纯前端数字滚动组件，基于 `requestAnimationFrame` 驱动帧循环，支持递增/递减、缓动函数、小数位、千分位分隔符与前后缀格式化，并通过 `defineExpose` 暴露 `start/pause/resume/reset` 控制方法。
依赖方向单向向外：各组件仅依赖 `@/hooks/web/useDesign`、`@/store/modules/*`、`@/utils/*` 等共享基础设施，彼此之间无相互引用。

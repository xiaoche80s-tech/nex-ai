- 组件统一使用 `<script lang="ts" setup>` 语法，并通过 `defineOptions({ name: '...' })` 显式声明组件名以便调试。
- Props 类型定义优先使用项目自研的 `@/utils/propTypes`（如 `propTypes.bool.def`、`propTypes.string.validate`）而非原生 `PropType`。
- 对外交互采用组合式 API 的 `defineEmits` 声明事件，并通过 `defineExpose` 暴露方法或响应式数据给父组件。
- 日期处理统一委托给 `dayjs` 与 `@/utils/formatTime` 中的 `getDayRange`、`getLast7Days`、`getDateRange` 等工具函数，避免在组件内手写日期逻辑。

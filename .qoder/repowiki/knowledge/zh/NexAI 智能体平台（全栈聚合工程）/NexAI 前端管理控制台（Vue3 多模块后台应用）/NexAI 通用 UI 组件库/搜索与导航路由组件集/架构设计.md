模块由三个相互独立的 Vue 3 单文件组件构成，均位于 `src/components/` 下并按功能分包：
- `Search/`：通过 `index.ts` 暴露 `Search` 组件，内部基于 `@/hooks/web/useForm` 和 `FormSchema` 配置驱动渲染查询表单，支持 inline/bottom 两种布局、展开/收起、自定义 action 插槽，并通过 `search`/`reset` 事件向外传递校验后的模型。
- `RouterSearch/`：无构建入口的单文件组件，以 `isModal` 切换弹框/顶部内联两种形态，使用 `router.getRoutes()` 本地过滤 `meta.title` 与 `path` 实现远程搜索，选中后调用 `router.push` 跳转，并监听 `Ctrl/Cmd+K` 快捷键打开。
- `ShortcutDateRangePicker/`：封装 `el-date-picker` 的 daterange 模式，内置昨天/最近7天/本月/最近30天/最近1年等快捷选项，通过 `defineExpose({ times })` 暴露时间范围供父组件读取，并以 `change` 事件双向同步。
三者均不互相依赖，仅共享项目级工具（`@/utils/propTypes`、`@/utils/formatTime`、`dayjs`、Element Plus），属于纯展示型 UI 子模块。

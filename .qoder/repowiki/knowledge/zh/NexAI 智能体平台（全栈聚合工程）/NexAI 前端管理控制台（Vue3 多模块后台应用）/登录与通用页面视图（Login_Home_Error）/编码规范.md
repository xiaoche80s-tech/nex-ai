- 每个页面组件顶部通过 `defineOptions({ name: '...' })` 显式声明组件名，便于调试与缓存标识。
- 登录态切换采用模块级 `ref` 配合 `useLoginState` composable 暴露 `setLoginState/getLoginState/handleBackLogin`，供多个表单组件共享当前模式。
- 表单子组件按职责拆分并在 `components/index.ts` 中统一 re-export，父组件通过命名导入组合使用。
- 错误页采用“薄壳”模式：页面只负责传递 `type` 与 `push('/')` 回调给共享 `Error` 组件，不包含具体 UI 逻辑。
- 首页数据与 ECharts 配置分离：业务类型定义在 `types.ts`，图表 options 放在 `echarts-data.ts`，页面内通过 `reactive` + `Promise.all` 并行加载后设置 loading。

- 通过 `pom.xml` 中注释掉非必需 `nexai-module-*` 依赖来按需裁剪编译范围，保持默认最小化依赖集。
- 外部敏感配置（API Key、Base URL 等）统一以 `${ENV_VAR:default}` 形式在 `application.yaml` 中声明，便于 Docker 环境变量注入。
- 对未启用的模块路径（如 `/admin-api/bpm/**`、`/admin-api/product/**` 等）在 `DefaultController` 中以统一的 `CommonResult.error(NOT_IMPLEMENTED, ...)` 返回友好提示，避免 404。
- 配置文件按功能段用 `--- #################### xxx 配置 ####################` 分隔，并在顶部通过 `spring.profiles.active` 切换 local/dev/docker 环境。

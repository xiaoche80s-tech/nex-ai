本模块是 Maven 多模块项目中的 `nexai-server` 可执行 jar 容器，自身几乎不含业务代码，仅承担装配职责：
- 入口类 `NexaiServerApplication` 通过 `@SpringBootApplication(scanBasePackages = ...)` 扫描 `${nexai.info.base-package}.server` 与 `.module` 两个包，把各子模块暴露的 Controller/Service/Configuration 纳入同一 Spring 上下文。
- `pom.xml` 中显式引入 `nexai-module-system`、`nexai-module-infra`、`nexai-module-ai` 三个核心模块，其余模块（member/report/bpm/pay/mp/product/trade/statistics/crm/erp/iot/mes/wms/im）默认注释以缩短编译时间，按需启用。
- 配置集中在 `src/main/resources/application.yaml`，通过 `spring.profiles.active=local` 切换环境；同时提供 `application-dev.yaml`、`application-docker.yaml`、`application-local.yaml` 等 profile 覆盖；AI 厂商密钥、向量库（Redis/Qdrant/Milvus）、Kafka/RocketMQ、WebSocket 发送器类型等均在 YAML 中以占位符注入。
- 运行时持久化与 AgentScope 工作区由 `nexai.ai.runtime.workspace.root=~/.agentscope/nexai/workspace` 指定，AgentScope 会话与事件 JSONL 落盘于 `.agentscope/workspace/1/...`。
- 构建产物为单 fat jar（`spring-boot-maven-plugin:repackage`），Dockerfile 基于 `eclipse-temurin:21-jre` 暴露 48080 端口并以 `JAVA_OPTS` + `$ARGS` 方式传入 JVM 参数与环境变量。
- 依赖方向单向向下：本模块 → 各 `nexai-module-*` 模块 → 框架 starter（如 `nexai-spring-boot-starter-protection`），本模块不反向依赖任何 module。

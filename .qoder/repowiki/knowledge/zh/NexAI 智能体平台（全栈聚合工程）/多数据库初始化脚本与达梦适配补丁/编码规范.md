- 每个数据库方言目录下均保持相同的文件命名约定：`ruoyi-vue-pro.sql` 承载业务表结构，`quartz.sql` 承载调度表结构，便于按环境切换。
- DDL 统一以 `DROP TABLE IF EXISTS` + `CREATE TABLE ... COMMENT '...'` 形式定义，字段普遍包含 `creator`/`create_time`/`updater`/`update_time`/`deleted`/`tenant_id` 等审计与多租户列。
- 达梦适配通过 Java SPI 机制实现：在 `META-INF/services/liquibase.database.Database` 中显式列出支持的 Database 实现类，新增方言只需追加一行。
- Flowable 引擎对达梦的兼容采用源码级 patch 方式，直接替换 `AbstractEngineConfiguration` 中的数据库类型映射（如将 `DM DBMS` 映射到 Oracle 类型）。

模块按数据库方言分目录组织：mysql/、postgresql/、dm/ 各自包含 `ruoyi-vue-pro.sql`（业务系统全量表结构）和 `quartz.sql`（Quartz 调度表），由外部部署流程分别导入对应数据库实例。dm/ 下额外包含一个 Java 子工程 `flowable-patch`，通过覆盖 `org.flowable.common.engine.impl.AbstractEngineConfiguration` 并在 `META-INF/services/liquibase.database.Database` 中注册 `DmDatabase`，将 Flowable/Liquibase 的数据库类型映射从 Oracle 切换为达梦；同时提供 `liquibase/database/core/DmDatabase.java` 与 `BooleanType.java` 完成达梦特有的数据类型兼容。依赖方向单向：SQL 脚本仅被导入执行，Java 补丁作为运行时类被 Flowable 引擎加载，二者互不依赖。
